## 今日核心问题

视觉皮层层级 V1→V2→V4→颞下皮层（IT）与卷积神经网络（CNN）之间，存在怎样的表征层面对应关系？目标驱动深度学习模型在多大程度上真正预测了生物视觉神经元的响应？当循环连接、纹理偏见和对抗样本进入图像时，这个类比在哪里开始崩溃——以及这个崩溃点本身告诉了我们什么？

---

## 一句话摘要

通过任务驱动优化的卷积神经网络，其中间层能定量预测灵长类 V4 和 IT 神经元 ~50% 的可解释方差，但这个成功本身暴露了一条更深的裂缝：生物视觉系统是一台由预测、反馈和概念驱动的**主动推断机器**，而不只是一个分层的特征检测器。

---

## 为什么重要

2012 年，AlexNet 在 ImageNet 竞赛中将 top-5 错误率从 26% 压缩到 15.3%，令计算机视觉界震惊。但同一时间，麻省理工学院（MIT）的一组神经科学家提出了一个不同的问题：这些人工网络是否不只是在识别图像，而是**像大脑一样**识别图像？

这不只是学术比较。如果深度神经网络真的使用了与灵长类视觉皮层相似的计算，那么：

1. 我们可以用可操控的人工系统来**系统地检验大脑理论**，因为人工网络的每个参数都可以测量和修改；
2. 我们可以利用大脑的演化优化**指导人工智能架构设计**；
3. 任何类比**崩溃的地方**——两者预测人类/猴子行为的地方产生分歧——就是大脑超出我们最好的人工视觉系统、指示着**未发现的计算原理**的地方。

这就是 CNN–视觉皮层类比的独特价值：不是为了证明"大脑就是 AlexNet"，而是把这面镜子用作诊断工具——镜子映出相似之处，但更重要的是，镜中碎裂的地方才是科学的金矿。

## 背景：从 Hubel-Wiesel 到视觉皮层的层级

理解这场类比必须从 1959 年一个安静的下午说起。

**David Hubel 和 Torsten Wiesel**（后来因此获得 1981 年诺贝尔奖）将微电极插入麻醉猫的初级视觉皮层（V1），发现了一件令他们自己都惊讶的事：大多数 V1 神经元对漫射光完全没有反应，却对特定**方向**的亮条（或暗条）响应剧烈。他们将这些细胞称为"简单细胞"（simple cells），它们有明确分隔的兴奋区和抑制区，能精确检测视野中某个小区域内某个方向的边缘。更令人着迷的是"复杂细胞"（complex cells）：它们同样有方向偏好，但对刺激的精确位置不敏感——它们编码的是**方向本身**，而不是方向加位置。

Hubel 和 Wiesel 提出的解释成为神经科学中最持久的模型之一：简单细胞由多个外侧膝状体（LGN）神经元以特定排列的方式汇聚驱动，形成对方向的偏好；复杂细胞则由多个简单细胞汇聚驱动，从而获得位置不变性。这是**层级计算**的原型：低层神经元检测局部特征，高层神经元通过汇聚获得不变性。

这个逻辑的延伸就是腹侧视觉流（ventral visual stream）：

```
视网膜 → LGN → V1 → V2 → V4 → IT（颞下皮层）
```

每一站都比上一站有**更大的感受野**（覆盖更大的视野区域）、**更复杂的偏好**（从方向到曲率到形状到物体身份）和**更强的不变性**（对位置、大小、视角变化的容忍）。终点 IT 皮层里，一个神经元可以对特定人脸、椅子或香蕉有稳健响应，无论它出现在视野的哪个位置。

**James DiCarlo、Davide Zoccolan 和 Nicole Rust（2012）** 在 Neuron 上的综述将这个过程称为"解开纠缠"（untangling）：不同物体的神经表征在 V1 中是高度纠缠的（无法用线性分类器区分），但在 IT 中变得线性可分——可以用简单的读出权重识别物体。这是腹侧流的核心计算成就（PMID:22325196，abstract only）。

---

## 从 Hubel-Wiesel 到卷积神经网络：工程师的致敬与意外的类比

卷积神经网络（CNN）的历史其实是对 Hubel-Wiesel 的一次工程致敬。

1980 年代，**Fukushima** 的新认知机（Neocognitron）直接根据 Hubel-Wiesel 的简单/复杂细胞框架设计：S 层（简单细胞）检测局部方向，C 层（复杂细胞）通过池化获得位置不变性。LeCun 随后引入反向传播，形成了现代 CNN 的基础。1999 年，**Riesenhuber 和 Poggio**（MIT）提出 HMAX 模型（PMID:10526343），正式从神经科学框架中推导出 S-单元（模板匹配）和 C-单元（MAX 池化）的计算流水线，并预测这个机制在 V4 和 IT 中都有类似实现。

然而，真正震动两个领域的是 2012 年之后的事件。AlexNet 出现后，多组研究人员开始定量问：**深度 CNN 的层级是否系统性地对应视觉皮层层级？**

---

## 关键机制（分层分析）

### 分子/细胞层：V1 简单细胞 ≈ CNN 第一层卷积核

这是类比最精确的地方。

CNN 第一层学习到的卷积核，当用图像补丁进行可视化时，大量表现为 **Gabor 滤波器**——与 V1 简单细胞感受野几乎完全相同的数学形式（方向性、空间频率调谐、ON/OFF 子区）。这不是巧合：两者都在尝试解决同一个问题（从局部像素中提取边缘和方向信息），并且似乎收敛到了同一个解。

卷积操作本身也与生物视觉中的**权重共享**（weight sharing）高度对应：V1 中同一方向偏好的神经元在整个视野的对应位置重复出现，功能上等价于用同一个卷积核扫描整张图像。

### 回路/区域层：CNN 深层 ≈ V4 和 IT

这是类比最令人惊讶的地方。

**Yamins 等（2014，PNAS，PMID:24812127，PMCID:PMC4060707，开放全文）** 做了一个关键实验：他们训练了超过 2000 个不同超参数的层次卷积神经网络，系统地测量每个网络：（a）在物体识别任务上的性能，（b）其中间层对猕猴 V4 和 IT 神经元响应的预测能力。

结果令人震惊：**识别性能与神经预测力之间存在强正相关（r=0.78）**。不是有一点相关，而是非常强的相关。最好的高性能模型，在没有任何神经约束的情况下，预测了：
- **IT 神经元响应的 48.5% 可解释方差**（显著优于此前所有模型）
- **V4 神经元响应的 51.7% 可解释方差**（网络中间层，而非顶层）

这暗示了一个深刻结论：**视觉皮层的层级结构可能是演化在视觉识别任务的约束下自然优化的结果，与工程师通过梯度下降达到的解殊途同归。** 目标决定结构。

**Cadieu 等（2014，PLoS Comp Biol，PMID:25521294，PMCID:PMC4270441，开放全文）** 进一步比较了深度神经网络与灵长类 IT 皮层的**表征性能**（而非仅仅神经响应编码）：当用相同的物体识别任务来评估时，最新的深度神经网络（Zeiler & Fergus 2013，Krizhevsky 2012）在多单元分析中与 IT 表现相当，在单单元分析中甚至超越 IT——而此前的所有视觉模型（V1 型、V2 型、HMAX）在同样任务上接近随机猜测水平。

### 表征层：IT = CNN 顶层的线性解码

**Khaligh-Razavi 和 Kriegeskorte（2014，PLoS Comp Biol，PMID:25375136，abstract only）** 将 37 个不同的视觉模型与人类和猴子的 IT 皮层进行表征相似度矩阵（RDM）比较。

核心发现：**监督训练的深度 CNN（在大规模标注数据集上训练物体类别）远超所有无监督模型**。无监督模型（HMAX、SIFT、GIST）基本无法解释 IT 的分类聚类结构，而经过监督学习的深度 CNN 则能重现 IT 表征中物体类别之间的相似度关系。

这引出了一个重要问题：**大脑是否也依赖某种类似"监督学习"的机制来建立 IT 的表征结构？** 这将我们导向发育关键期、奖励学习与表征形成的交叉地带——我们将在未来文章中深入。

## 比喻：翻译机与原著

想象你雇了一位翻译，将一部精妙的中文小说翻译成英语。你惊讶地发现，这位翻译的英文译本与人类专业翻译的结果几乎一模一样——在语义、结构、节奏上都高度相似。你开始认为翻译机"理解"了小说。

**这个比喻在哪里有效**：翻译机（CNN）和人类翻译（IT 皮层）都能完成同一个最终任务（识别物体/翻译文字），产生惊人相似的中间表征。这种相似不是偶然的，而是被相同的任务约束所塑造的。

**这个比喻在哪里失效**：当你告诉翻译机"这个句子是反讽"或"作者在这里故意用了残缺的语法来模仿主人公的精神状态"时，翻译机迷失了。翻译机处理的是词语的统计规律，而人类翻译理解的是**意图**。类似地：

- 告诉 CNN 图像被加了**几乎不可感知的噪声**（对抗样本）时，CNN 把猫识别成吐司；人类毫不受影响
- 将所有局部纹理打乱（只保留全局形状）时，CNN 困惑，人类仍能识别
- 在极度遮挡或嘈杂条件下，CNN 失败的速度远比人类快

这说明翻译机掌握了一部分同样的"规则"（识别任务的表征结构），但缺少人类视觉使用的某些更深的计算原则。

## 类比的崩溃：三个裂缝

这是今天文章最重要的部分。CNN–视觉皮层类比的成功越来越清晰，但它崩溃的方式同样清晰，且更具科学价值。

### 裂缝一：循环连接与时间

纯前馈 CNN 是一次性的前向信号流：像素进入，类别标签输出，中间没有回路。

然而，灵长类视觉系统中，**腹侧流充满了反向投射**：V2→V1 的连接数量与 V1→V2 相当，高级区域（IT、PFC）向低级区域的反馈投射在解剖上大量存在。

**Kar 等（2019，Nat Neurosci，PMID:31036945）** 用一个聪明的实验揭示了这些循环连接的功能重要性。他们用**神经错时图像学**（neural co-tracking）在 IT 皮层中找到每张图像"令 IT 神经元形成足够一致表征"所需的时间——大多数"容易"图像在初始 ~100ms 的前馈扫描后即完成；但一些经过特殊设计的"困难"图像（视觉上被部分遮挡、或对象与背景对比度低）需要额外约 30ms 的延迟才能在 IT 中形成稳定表征。

这额外的 30ms 正好是信号往返于更高视觉区域或皮层内循环所需的时间。更关键的是：这些"困难"图像在前馈 CNN 模型中预测误差最大——CNN 的困难和大脑的困难不一样。但当研究者在 CNN 中加入**循环连接层**（recurrent units）时，对这些困难图像的神经预测力显著提升。

**意义**：视觉皮层不只是前馈的特征探测器，它是一台**迭代精细化的推断机**。困难图像需要反馈——也许是从更高级区域传来的先验预测，帮助低级区域消解歧义。

### 裂缝二：纹理偏见与形状偏见

**人类视觉系统是形状优先的（shape bias）**：当你看到一只拥有大象纹理的猫形轮廓时，你会说"这是猫"。形状告诉你物体的身份，纹理只是表面信息。

**CNN 默认是纹理优先的（texture bias）**：当同样的刺激呈现给在 ImageNet 上训练的标准 CNN 时，它会说"这是大象"。Geirhos 等（2019，ICLR 2019，arXiv:1811.12231，无 PubMed PMID）用大量"风格迁移"图像（正常形状+异类纹理）系统证明了这一点。

这个差异的来源可能是：大规模图像数据集中，纹理是**物体类别的强预测因子**（草原动物 → 草地纹理，水鸟 → 蓝色水面），CNN 学会了走纹理捷径。灵长类视觉系统经历的是一个**以形状理解为目标**的漫长演化，其中轮廓、三维结构和视角不变性受到更强的选择压力。

当研究者用特意扩展形状信息的数据集（如 Stylized-ImageNet）微调 CNN 时，网络变得更像人类（形状偏见增强），同时**对真实 IT 神经元的预测力也提高了**——这再次证明 IT 本身是形状优先的。

### 裂缝三：对抗样本与表征的深层分歧

CNN 对**对抗样本（adversarial examples）** 的脆弱性是类比崩溃最戏剧性的地方。

对人眼完全无法区分（像素差异远小于 JND）的两张图像，可以使 CNN 从极高置信度的"猫"翻转到极高置信度的"飞机"。这说明 CNN 的决策边界与人类视觉系统的决策边界在高维表征空间中走了非常不同的路径——在 IT 神经元能轻易区分的视觉区域内，CNN 的表征空间存在令人惊讶的"裂缝"。

反过来也成立：**Bashivan、Kar 和 DiCarlo（2019，Science，PMID:31048462）** 用 CNN 驱动图像合成方法，生成能精确控制猕猴 V4 神经元响应的图像——甚至将特定神经元的响应推高到超出自然图像刺激所能达到的范围。这一成功恰恰说明 CNN 对 V4 的预测力足够高，以至于可以通过 CNN 的视角"编程"V4 神经元。

但这些合成图像——它们在生物神经元中引发极端响应——对人类观察者来说通常是毫无意义的、令人困惑的抽象图案。CNN 找到了一种工作方式，能精确驱动神经回路，但这种方式并不对应于大脑通常用于识别现实世界物体的表征子空间。这是一种另类的"对抗样本"：对生物视觉系统起作用但对人类感知毫无意义的刺激。

## 它如何改变我们对大脑的理解

CNN–视觉皮层类比最重要的遗产不是"大脑是一个 CNN"，而是三个更微妙的结论：

**1. 任务决定架构（task shapes structure）**

Yamins 等（2014）的结果说明，腹侧流的层级结构很可能是视觉识别任务的自然约束所塑造的，而不是任意的解剖安排。这使得"大脑为什么长这样"变成了一个可回答的工程问题——从任务反向推导最优架构。

**2. 神经预测力是可量化的科学指标**

"一个模型在多大程度上解释了神经元响应"现在有了精确的数学定义。Brain-Score（MIT 维护的基准）将这种比较标准化，使神经科学能够对不同理论进行**定量裁判**——哪个计算假设最好地解释了视觉皮层的神经数据？

**3. 类比的崩溃处是最有趣的科学**

循环连接的重要性（Kar 2019）告诉我们：视觉皮层是一个**迭代推断系统**，而不是一个单次前馈处理器。形状偏见的差异告诉我们：IT 的表征受到**概念/知识结构**的影响，而不只是统计规律学习。对抗样本的差异告诉我们：生物视觉在**表征空间的几何结构**上与 CNN 有根本差异——可能与三维物体先验、因果结构认识、或运动预测整合有关。

所有这些"崩溃点"都是大脑超出 CNN 的地方，也都是神经科学未来的研究前沿。

## 争议与未解问题

### 未解问题一（Q-cnn-vc-01，高优先级）：循环连接究竟在做什么？

Kar 等（2019）证明了循环处理在困难任务中不可或缺，但"循环连接究竟计算了什么"仍不清楚。是从高级区域传来的预测（预测编码框架）？还是 IT 内部的吸引子动力学？还是两者都有？

**检验方法**：光遗传学在困难视觉任务时段特异性阻断 V4→V1 或 IT→V4 反馈，对比"容易"和"困难"图像的识别率变化。

### 未解问题二（Q-cnn-vc-02，高优先级）：监督学习的类比

Khaligh-Razavi & Kriegeskorte（2014）发现监督 CNN 而非无监督 CNN 解释 IT 表征——但大脑显然没有使用 ImageNet 标签。大脑的"监督信号"是什么？是奖励系统（多巴胺预测误差）？是运动结果？是语言标签（对于人类）？

### 未解问题三（Q-cnn-vc-03，中优先级）：形状 vs 纹理偏见的皮层来源

IT 的形状偏见是从哪一层开始出现的？V4 是否已经是形状主导？还是只有 IT 才完成从纹理到形状的转变？高分辨率 fMRI 和灵长类侵入性记录结合 Geirhos 型刺激可以直接回答这一问题。

### 竞争性观点：分布式计算 vs 局部层级

近年来，一些研究（Zhuang et al. 2021，PNAS，PMID:33431673）发现，无监督的对比学习（self-supervised CNN）在神经预测力上已接近监督模型。这挑战了"监督信号是必须的"的结论，暗示**任务无关的统计结构**可能足以产生类 IT 表征。目前这仍是开放争论。

## 今日概念卡片

**腹侧视觉流的核心计算任务**  
将视网膜上的二维像素流"解开纠缠"：使不同物体在 IT 皮层的神经表征变得线性可分，同时对物体的位置、大小、视角和光照条件保持不变性。这个过程需要在每个阶段（V1→V2→V4→IT）同时扩大感受野（获取更多上下文）并精细化特征（从边缘到部件到物体）。

**目标驱动模型的核心发现**  
在层次卷积神经网络中，识别性能与神经预测力之间存在强相关（r=0.78）——这表明演化和工程优化在同一任务约束下收敛到了相似的表征解。
