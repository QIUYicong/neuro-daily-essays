# TARP（跨膜 AMPAR 调控蛋白）(Transmembrane AMPAR Regulatory Protein / TARP)

> **一句话定义**：AMPA 受体的辅助亚基，其 C 末端通过 PDZ 结合基序与 PSD-95 直接结合，构成 AMPAR-TARP-PSD-95 三元复合物——这是将 AMPA 受体锚定于兴奋性突触"槽位"的分子中介。

## 当前理解

我们现在认为，TARP（以 Stargazin/γ-2 为原型成员）是 AMPA 受体在突触后膜精确定位的必要中介。AMPA 受体本身不含能直接结合 PSD-95 PDZ 域的序列；TARP 充当桥接分子，使 AMPAR 能够借助 PSD-95 的槽位系统被稳定锚定于突触后致密体（PSD）。TARP 还调控 AMPAR 的门控动力学（通过与谷氨酸受体跨膜段的接触）和表面运输（从内体到膜再到突触），因此是整个兴奋性突触传递机器的核心辅助成分。

## 关键机制

- **TARP 家族**：8 个成员（γ-1 至 γ-8，又称 CACNG1-8）；与 AMPAR 功能相关的主要是 γ-2（Stargazin）、γ-3、γ-4、γ-8（海马高表达）
- **突触锚定**：TARP C 末端含有 **PDZ 结合基序**（-TTPV，Stargazin 末端）→ 与 PSD-95 PDZ1/2 直接结合（Schnell 2002，PNAS，PMID:12359873 / PMC129795，开放全文）
- **Stargazin 突变实验**：突变 TARP 的 PDZ 结合基序后，AMPAR 表面量正常，但**无法在突触处聚集**（说明 TARP-PSD-95 链是突触定位必要条件，而非可选）
- **门控调节**：TARP 与 AMPAR 跨膜段相互作用，减缓失活、增加开放概率
- **表面递送**：TARP 参与 AMPAR 从内质网→再循环内体→细胞膜的运输过程
