# CNTNAP2 / CASPR2（接触蛋白关联蛋白样 2）

> **一句话定义**：CNTNAP2 是人类基因组最大基因之一（7q35，2.3 Mb），编码神经素超家族跨膜粘附蛋白 CASPR2；成熟轴突中锚定旁节区 Kv1 钾通道，发育期调控 GABA 能中间神经元迁移与定位；FOXP2 直接转录抑制 CNTNAP2，使两者共同构成语言障碍-孤独症-癫痫三角共病的分子通路。

## 当前理解

我们现在认为，CNTNAP2/CASPR2 具有**双重功能身份**：成熟神经系统中的轴突绝缘组件，以及发育期神经元迁移的导引因子。两者的分离正是理解 CNTNAP2 相关疾病谱系的关键。

**分子特征**：CNTNAP2 基因跨越约 2.3 兆碱基（7q35），是人类最大基因之一，24 个外显子编码 1331 氨基酸的 CASPR2 蛋白。CASPR2 属于神经素超家族，具有 Laminin-G 和 EGF 样胞外结构域，以及参与胞内 K⁺ 通道锚定的胞质区域。

**成熟功能**：有髓轴突旁节区，CASPR2 与 Contactin-2（TAG-1）形成细胞粘附复合物，将 Kv1.1/Kv1.2 延迟整流钾通道固定在郎飞节两侧，防止动作电位传导漏电，确保高速跳跃式传导的保真度。

**发育功能（更关键）**：胚胎皮层发育期，CASPR2 高度表达于脑室区/室下区（皮层兴奋性神经元出生地）以及**神经节隆起（MGE/CGE）**——GABA 能中间神经元出生地。Peñagarikano 等（2011）证明 CNTNAP2 敲除导致 PV+/CR+/NPY+ 中间神经元在皮层、纹状体和海马中数量显著减少，并伴随上层皮层神经元（CUX1+）的层位异常定位和白质异位神经元——提示 CASPR2 是中间神经元迁移导引链条的一个必要成员。

**调控上游**：FOXP2 直接结合 CNTNAP2 内含子并显著抑制其转录（Vernes et al. 2008, PMID:18987363）。这条抑制关系解释了为何 FOXP2 突变（罕见、高外显率）和 CNTNAP2 变异（常见、低外显率）都影响语言发育——两者处于同一调控轴的不同层级。

**发育期语言回路富集**：发育期人脑中，CNTNAP2 表达优先富集于前额叶皮层、前颞叶和前扣带皮层（Alarcon et al. 2008, PMID:18179893），正是语言和社会认知的核心网络区域，这是 CNTNAP2 变异选择性影响语言能力的空间遗传学解释。

## 关键机制

### 分子层：Kv1 通道锚定

旁节区机制：CASPR2 + Contactin-2 → Kv1.1/Kv1.2 锚定 → 动作电位传导期间防止漏电流 → 跳跃传导效率和保真度维持。

### 发育层：GABA 能中间神经元迁移

```
MGE/CGE → 神经元出生 → 长距离迁移至皮层/纹状体/海马
CASPR2 ← 在迁移路径上提供细胞粘附导引信号
CASPR2 缺失 → PV+/CR+/NPY+ 中间神经元减少（全层，皮层/纹状体/海马）
             → CUX1+ 上层神经元滞留深层（层位迁移异常）
             → 胼胝体异位神经元（持续至成体）
```

### 回路层：E/I 失衡与振荡崩溃

中间神经元减少 → mPFC L2/3 锥体细胞的兴奋性+抑制性突触输入均减少（Lazaro 2019）→ delta/theta 相位锁定降低 → 振荡时序协调崩溃 → 认知控制和语言回路功能受损。

幸存抑制性神经元活动代偿性增加，但失去时序协调性——产生"有抑制但无节律"的前额叶状态。

### 神经内分泌层：OXT 系统联动

CNTNAP2 缺失 → 下丘脑 PVN 催产素神经元减少 → 全脑 OXT 水平下降 → 伏隔核（NAc）OXT 受体信号不足 → 社交奖励减弱 → 社交退缩。早期慢性 OXT 给药可部分恢复 PVN OXT 神经元数量和行为（Peñagarikano 2015）。

### 细胞外基质层：PNN 过度沉积

CNTNAP2 KO 的 mPFC 中 PNN（围神经元网）过度包裹 PV 细胞（Gandhi 2023）→ PV 细胞异常封锁 → 社交回路可塑性降低。ChABC 消化 PNN 部分救援社交互动（不救援刻板行为）→ 分离性表明社交和重复行为有不同底物。
