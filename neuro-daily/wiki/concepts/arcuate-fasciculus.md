# 弓状束 (Arcuate Fasciculus, AF)

> **一句话定义**：连接后颞叶（含Wernicke区附近）与额叶下回（Broca区BA44）的弓形白质通路，是背侧语言流的核心解剖基础；出生时髓鞘化程度低，随儿童句法习得而成熟；损伤导致传导性失语。

## 当前理解

我们现在认为，弓状束（AF）是背侧语言流的主干通路，将颞顶界面区（Spt，音韵短期缓冲）与Broca区（BA44，句法层级运算）连接起来。

**三个关键特性**：

1. **左侧优势**：弓状束在左半球明显粗于右半球，这一不对称性与语言产出和句法处理的左半球优势高度对应。DTI（弥散张量成像）研究一致发现左侧AF体积>右侧。

2. **发育时间线**：AF是大脑髓鞘化最晚的白质通路之一。出生时髓鞘化程度极低，在儿童期3–7岁期间随句法习得逐渐成熟。Friederici的纵向研究显示，AF髓鞘化进度**预测**儿童句法理解准确率和速度——这提供了白质发育与语言认知发展之间的直接证据。

3. **传导性失语标志**：AF损伤（或颞顶界面区Spt损伤）导致**传导性失语**（conduction aphasia）：患者能理解语言（腹侧流完整），能流利产出语言（运动区完整），但**不能准确重复**听到的词语——因为音韵短期信息无法从颞叶传递到额叶进行发音程序化。

**弓状束≠"Broca-Wernicke连线"**：经典Geschwind模型认为AF是连接Wernicke区（语言理解）到Broca区（语言产出）的"电话线"。现代理解更准确：AF是背侧流中承载**音韵时序信息和句法程序**的通路，不是语言理解的通道（这主要走腹侧流的IFOF/UF）。

## 关键机制

```
颞顶界面区（Spt）← 后颞叶/Wernicke区附近
    │
    │（弓状束AF，左侧主导）
    │
    ▼
Broca区BA44（pars opercularis）
    │
    ▼
运动前区（premotor）+ SMA + 运动皮层
    │
    ▼
发音动作输出
```

AF传递的信息：音韵时序序列的短期记忆表征（"刚才听到的词的发音程序"）→ 转化为发音计划 → 运动输出
