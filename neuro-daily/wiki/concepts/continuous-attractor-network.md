# 连续吸引子网络 (Continuous Attractor Network, CAN)

> **一句话定义**：具有平移对称循环连接的神经网络模型，通过"墨西哥帽型"（中心兴奋-环形抑制）连接产生稳定的"活跃凸块"（activity bump），凸块位置编码连续参数（位置/方向）并随速度输入平滑平移；是路径整合和网格细胞生成的主流计算模型，Gardner 2022 的拓扑数据分析已直接证实其预测的环面拓扑结构。

## 当前理解

连续吸引子网络（CAN）模型是解释网格细胞生成和路径整合机制的主流计算框架。它的核心洞见是：一个具有特定对称连接结构的循环神经网络，可以产生一系列**连续的吸引子状态**，形成一个"稳定流形"——网络会自发趋向流形上的某个状态，并在没有扰动时保持在那里；当外部输入（速度信号）将激活推动时，网络就像在流形上"滑动"，从一个吸引子状态平滑过渡到相邻状态。

McNaughton 等（2006，PMID: 16858394）在理论框架中系统阐述了 CAN 模型的网格细胞应用；Burak & Fiete（2009，PMID: 19229307，开放全文 PMC:2632741）对模型进行了数学精确化，并定量分析了不同边界条件对路径积分精度的影响。Gardner 等（2022，PMID: 35022611，开放全文 PMC:8810387）使用拓扑数据分析（TDA）首次直接证实了 MEC 网格细胞群体活跃的流形是一个**二维环面（T²）**——这是 CAN 模型对路径整合状态空间的核心预测，也是迄今对 CAN 模型最有力的实验验证。

## 关键机制

### 1. 中心兴奋-环形抑制（"墨西哥帽型"连接）

CAN 的基本连接规则：在功能空间（按细胞编码偏好排列的神经元坐标系）中：
- **近距离神经元**：相互兴奋（通过直接兴奋性突触）
- **中距离神经元**：相互抑制（通过 GABAergic 中间神经元介导）
- **结果**：一个局部活跃"凸块"（bump）被周围的抑制环绕，形成稳定的局部激活岛

在垂直剖面上看，这种活跃模式的形状类似"墨西哥帽"（Mexican hat）——中间高、两侧低的形状。

### 2. 吸引子动力学

由上述连接产生的关键动力学特性：
- 凸块在功能空间中是**稳定**的：小扰动后，网络恢复到凸块形状（不会崩溃或随机漂移）
- 凸块可以位于功能空间中的**任何位置**：每个位置都是一个合法的吸引子状态（这形成"连续"吸引子，对比 Hopfield 网络的离散记忆吸引子）
- **凸块的位置 = 大脑对连续参数（位置、方向）的当前估计**

### 3. 速度驱动的凸块平移

当外部速度信号输入时，凸块在功能空间中**平滑移动**：
- 方向选择性的不对称连接权重：不同头朝向的联合细胞（conjunctive cells）对凸块施加方向性推力
- 头朝向 θ + 速度 v → 凸块在功能空间中的平移速度 = k × v（k 为编码增益）
- 凸块的当前位置 = 起点 + ∫₀ᵗ v(s)ds = 路径整合结果

### 4. 环面拓扑：最优路径积分的几何解决方案

**为什么是环面，不是平面？**

如果神经元的网格相位偏好（φ_x, φ_y）在功能空间中均匀排列在 [0, 2π) × [0, 2π) 的方形上，且边界**周期性地衔接**（即相位 0 和 2π 的神经元彼此连接），则：
- 功能空间在数学上等价于一个**二维环面 T²**（方形四边两两粘合形成甜甜圈）
- 凸块在这个环面上移动，不存在边界效应（不会被"推"到边界外）

**Burak & Fiete 2009 的定量结论**：
- 无周期性边界（平面）的 CAN：路径积分误差 ∝ √t，且边界附近存在额外系统误差
- 有周期性边界（环面）的 CAN：路径积分误差仍然 ∝ √t（扩散不可避免），但扩散系数降低 **5–10 倍**，且无系统偏差
- 误差增长公式：σ_pos(t) ≈ √(CV² × D × t)，其中 CV 为速度信号变异系数，D 为扩散系数

### 5. Gardner 2022 的直接拓扑验证

Gardner等（2022，Nature，PMID: 35022611）的拓扑数据分析（TDA/持续同调）：
- 分析8只大鼠 MEC 的7671个网格细胞的群体活跃高维数据
- 用持续同调识别高维群体活跃流形的"洞"结构（即拓扑特征）
- 结果：拓扑指纹为**两个 1-阶环（two 1-cycles）+ 一个 2-阶空腔（one 2-cycle）** = 二维环面 T² 的唯一拓扑标志
- 流形在不同环境（r=0.79）和睡眠-清醒状态（r=0.80–0.83）间保持稳定
- **排除振荡干涉（OI）模型**：OI 模型中相位在平面上展开（非周期性），不能产生环面拓扑

### 6. CAN 与头向细胞系统

CAN 模型最初被用于解释**头向细胞系统**（1D 版本）：
- 头向细胞偏好朝向在 0–360° 均匀分布，形成**环形吸引子（一维环面 S¹）**
- 类似机制：中心兴奋（相同偏好方向的细胞互相兴奋），环形抑制，头部旋转速度驱动凸块沿环转动
- 头向系统的 1D 环形吸引子和网格系统的 2D 环面吸引子，是 CAN 原理在不同编码维度上的同一计算架构

## 与 Hopfield 网络的区别

| 特性 | CAN（连续吸引子） | Hopfield 网络（离散吸引子） |
|------|-----------------|---------------------------|
| 吸引子数量 | 无限多（连续流形） | 有限多（离散记忆状态） |
| 吸引子性质 | 连续排列，任意位置 | 稀疏离散，特定模式 |
| 功能 | 编码连续参数（位置/方向） | 模式补全（联想记忆） |
| 神经底物 | MEC（路径积分）、PoS/ADN（头向） | CA3（空间记忆联想） |
| 信息写入 | 实时速度输入更新凸块位置 | Hebbian 学习写入固定记忆 |
