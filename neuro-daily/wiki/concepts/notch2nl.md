# NOTCH2NL（人类特异性皮层扩张基因）

> **一句话定义**：一组人类（和 Neanderthal/Denisovan）特有的 Notch 受体旁系同源基因，通过延长皮层祖细胞的自我更新增加神经元产量，其基因组拷贝数直接与脑容量大小相关（缺失→小头症，重复→大头症）。

## 当前理解

我们现在认为，NOTCH2NL 是人类大脑相对于其他灵长类实现体积扩张的关键分子机制之一。这组基因（NOTCH2NLA/B/C/R）由 NOTCH2 受体的前四个外显子通过节段性基因组重复而来，出现于大约 300–400 万年前（人类-黑猩猩分化后），时间点与化石记录中人类祖先脑容量开始快速增大高度吻合。

NOTCH2NL 的功能机制：通过细胞自主方式降低细胞膜表面 DLL1 配体的可用性，从而激活 Notch 信号通路，延缓皮层祖细胞分化、促进自我更新，最终产生更多神经元。

在人类诱导多能干细胞来源的皮层类器官中，过表达 NOTCH2NLB 的克隆细胞数量在相同时间窗内增加约 3 倍，验证了功能效应。

**1q21.1 CNV 临床证据（自然实验）**：
- 1q21.1 缺失（减少 NOTCH2NL 拷贝数）→ **小头症**，提示 Notch 信号不足 → 祖细胞过早分化 → 神经元总数减少
- 1q21.1 重复（增加 NOTCH2NL 拷贝数）→ **大头症**，提示 Notch 信号过强 → 祖细胞自我更新延长 → 神经元总数增加

这为「NOTCH2NL 拷贝数 ↔ 脑容量」提供了人类在体的直接因果证据。

## 关键机制

**细胞自主 Notch 激活**
1. NOTCH2NL 蛋白在皮层祖细胞（RGC/oRG）细胞表面降低 DLL1 可用性
2. DLL1 减少 → 邻近细胞的 Notch 信号降低（反向效果）
3. 自身 Notch 信号激活 → 维持 Sox2/Pax6 高表达 → 促进自我更新
4. 净效应：祖细胞池多维持数轮分裂，产生更多神经元

**进化时间线**
- 约 3–4 百万年前：节段性重复产生 NOTCH2NL 前体
- 约 2–3 百万年前：基因活化为功能性蛋白
- 现代人类：3 个活性拷贝（NOTCH2NLA/B/C）
- Neanderthal / Denisovan：也具有 NOTCH2NL 拷贝（全基因组测序证实）
- 黑猩猩/大猩猩：无活性 NOTCH2NL 拷贝
