# Henneman 大小原则 (Henneman's Size Principle)

> **一句话定义**：脊髓 α运动神经元按胞体大小决定的输入电阻顺序被招募——小型（高输入电阻）运动神经元阈值低、先放电，大型（低输入电阻）运动神经元阈值高、后放电；这一规则由细胞物理学自动实现，无需中枢调度。

## 当前理解

我们现在认为，Henneman 大小原则（1957/1965）是运动控制系统最优雅的设计之一：通过神经元大小的物理差异，把"共同突触驱动的强度"自动转化为"有序的运动单元招募"。

**核心物理机制**：
- 输入电阻 R_in ∝ 1/（胞体表面积） → 小型 α-MN 的 R_in 更高
- 在相同突触电流 I 下：ΔV = I × R_in → 小型 α-MN 的去极化幅度更大
- 因此小型 α-MN 更容易到达放电阈值 → 先被招募

**力量调控逻辑**：大脑只需调节输送给运动神经元池的"共同驱动电流"强度，运动单元就会自动按 S → FR → FF 的顺序激活，实现从最小力量（仅少数 S 型单元）到最大力量（全部三类都激活）的连续调节。

**2023 年修订（Hug et al., PMID:36353890, PMC10098498）**：大小原则最严格地适用于接受相同"共同突触输入"的功能性神经元簇内部，而非整个肌肉的全部运动神经元。当不同神经元簇接受不同的驱动，各簇内部仍遵循大小原则，但跨簇比较可以出现高阈值单元与低阈值单元同时激活的现象。这是对原则的**精化而非否定**。

## 关键机制

### 为什么是"物理自动决定"？

```
大脑给运动神经元池施加共同突触驱动
    ↓
所有 α-MN 接受相同（或近似相同）的突触电流
    ↓
小型 α-MN（高 R_in）: ΔV = I × R_in → 更大去极化 → 先到达阈值 → 先放电
大型 α-MN（低 R_in）: ΔV = I × R_in → 更小去极化 → 后到达阈值 → 后放电
    ↓
招募顺序自动锁定：S → FR → FF
（无需皮层或脑干的精确"点名"控制）
```

### 与三类运动单元的对应

大小原则的招募顺序与三类运动单元的代谢和功能特征完美对应——不是偶然：
- 小型 S 型（低阈值，先招募）：高效氧化代谢，适合长时间激活
- 大型 FF 型（高阈值，后招募）：快速糖酵解，适合短暂高强度激活

在大多数日常活动中，只有小型、高效的运动单元被激活；大型、高耗能的运动单元只在真正需要最大力量时才参与。这是一种"节能优先"的设计原则。

### 例外与争议

1. **任务特异性招募**：部分实验报告在快速冲击性运动或某些姿势控制任务中，高阈值单元可能在低阈值单元之前激活。这些观察存在方法学争议（表面 EMG 的采样偏差）；且多数研究者认为，共同突触输入在不同神经元簇间的差异性分配，可以在不真正违反物理原则的情况下产生表面上的"逆序"。

2. **Hug 2023 修订**：功能性簇内严格有序，跨簇不保证有序，是当前最稳健的理解框架。
