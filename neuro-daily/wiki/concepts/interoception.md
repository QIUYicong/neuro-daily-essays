# 内感受 (Interoception)

> **一句话定义**：内感受是大脑对身体内部状态（心率、呼吸、内脏、皮肤导电、肌肉张力等）的感知与预测性建模能力，是情感意识、共情和自我感的生理基础。

## 当前理解

我们现在认为，内感受不是一个被动的"身体信号接收系统"，而是一个**主动的预测编码过程**（Barrett & Simmons 2015，PMID:26016744）。

**经典观点**（James-Lange vs. Cannon-Bard 之争）：20 世纪的长期争论是"情感是身体反应引发的感知（James-Lange）"还是"情感独立于身体在大脑中产生（Cannon-Bard）"。现代神经科学通过内感受预测编码框架，整合了两者：情感体验既依赖于身体信号的上行，也依赖于大脑对身体状态的自上而下预测。

**EPIC 模型（Embodied Predictive Interoception Coding）**：
- 无颗粒型内脏运动皮层（前岛叶前部 + 内侧前额叶）→ 发出内感受**预测**（visceromotor predictions）
- 颗粒型内感受皮层（后岛叶 / 中岛叶）→ 接收上行身体信号，计算**预测误差**
- 预测误差信号上行更新高层预测模型
- 最终在前岛叶生成对身体状态的**当前最佳估计** = 情感感受

**内感受准确性（Interoceptive Accuracy, IA）**：感知自身心跳、呼吸等内感受信号的准确程度。高 IA 与更强的情感共情能力正相关——支持内感受是共情的机制基础。

**后→前岛叶梯度**（Craig 2009，PMID:19096369）：
| 区域 | 输入 | 功能 |
|------|------|------|
| 后岛叶（颗粒型）| 脊髓丘脑束（痛、温、触、内脏）| 初级内感受定位 |
| 中岛叶（不完全颗粒型）| 后岛叶 + 边缘系统 | 内感受整合 |
| 前岛叶（无颗粒型）| 中岛叶 + 前额叶 + 扣带回 | **内感受意识：转化为主观感受** |

## 关键机制

### 内感受的神经通路
1. 内脏/皮肤/肌肉 → 脊髓背角（特定 I 层神经元）→ 脊髓丘脑束 → 丘脑 → 后岛叶（初级内感受皮层）
2. 后岛叶 → 中岛叶 → 前岛叶（高级整合）
3. 前岛叶 → 前扣带回、下丘脑、杏仁核（情感-动机输出）

### 预测误差更新
- 前岛叶"预期"某种内感受状态（基于情境和过去经验）
- 当实际信号与预测不符 → 预测误差 → 更新内感受模型
- 这一循环持续运行，维持身体稳态（allostasis）和情感调节

### 内感受与情感：James-Lange 整合
- 内感受信号不直接产生情感——而是作为证据，更新大脑对身体当前状态的预测性表征
- 情感体验 = 内感受预测（带有过去情感学习权重）+ 当前情境
