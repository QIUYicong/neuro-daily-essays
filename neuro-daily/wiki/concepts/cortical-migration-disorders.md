# 皮层迁移障碍（Malformations of Cortical Development, MCD）

> **一句话定义**：因神经元放射状迁移（兴奋性神经元）或切向迁移（抑制性中间神经元）出现遗传性或获得性障碍，导致皮层层叠结构异常的一组疾病，主要包括无脑回/皮质下带状异位、脑室旁灰质异位、多小脑回和裂脑畸形。

## 当前理解

皮层迁移障碍（MCD）是一组因胎儿期（约 6–24 孕周）神经元迁移异常引起的先天性皮层结构畸形。MCD 是婴幼儿难治性癫痫的重要病因，约 20–40% 的难治性癫痫患者存在 MCD 相关皮层改变。

### 经典分类（Barkovich 分类）

| 类型 | 形态 | 主要机制 | 代表基因 |
|------|------|---------|---------|
| I 型无脑回（agyria/pachygyria） | 皮层光滑或粗大脑回，4 层 | 放射状迁移不足（dynein/MT 故障或停止信号缺失） | LIS1、DCX、RELN、ARX |
| II 型无脑回（鹅卵石型） | 皮层表面不规则，边界缺失 | 放射状迁移过度（基底膜破裂） | POMT1/2、FKRP、LARGE |
| 皮层下带状异位（SBH）| 皮层下"双皮层"条带 | 放射状迁移部分停止（DCX 杂合女性） | DCX（X 染色体） |
| 脑室旁灰质异位（PNH） | 侧脑室壁节结状异位灰质 | 神经元无法离开脑室区（cytoskeletal/移动起步） | FLNA（Filamin-A）、ARFGEF2 |
| 多小脑回（PMG） | 过多细小脑回，分层紊乱 | 迁移过早停止/局部增殖异常/板层组织失败 | GPR56、TUBB2B、局部缺血 |
| 裂脑畸形（Schizencephaly）| 穿透皮层全层的裂隙 | 局部神经元缺失/迁移严重障碍 | EMX2（部分）、局部损伤 |

### 致病机制的三层框架

1. **迁移机械层**（放射状迁移的动力）：
   - LIS1/PAFAH1B1 → dynein/微管调节 → 核移位
   - DCX → 微管束化 → 核移位
   - FLNA（Filamin-A）→ 肌动蛋白-细胞外基质连接 → 起始迁移

2. **导航-终止层**（迁移方向与停止）：
   - RELN/Reelin → ApoER2/VLDLR → Dab1 → 就位信号
   - p35/CDK5 → 调控 outside-in vs inside-out（p35-/- 小鼠：皮层层序倒转，但机制不同于 reeler）

3. **边界维持层**（皮层物理边界）：
   - α-dystroglycan 糖基化（POMT1/FKRP 等）→ 基底膜完整性 → 阻止过度迁移

### 与切向迁移障碍的关系

中间神经元切向迁移（MGE/CGE→皮层）故障也可引起皮层功能紊乱（见 [[tangential-migration]]），但典型表现不是皮层折叠异常，而是 E/I 失衡、癫痫易感性增加、精神分裂症/自闭症风险。MCD 通常指放射状迁移障碍，但严重 MCD 也会继发中间神经元迁移异常。
