# 路径整合 (Path Integration)

> **一句话定义**：大脑通过持续积累自身运动速度矢量（速度×方向）来估计当前位置的机制，不依赖外部地标；是在黑暗或无标志环境中导航的神经基础，但随时间积累误差，需要地标校准。

## 当前理解

我们现在认为，路径整合是大脑主动"预测当前状态"的最清晰例子之一：即使完全没有外部感觉输入（视觉、嗅觉、听觉），大脑仍能维持对自身位置的连续估计，仅靠整合从前庭系统、本体感受和视觉光流获得的自身运动信号。

路径整合由MEC的网格细胞和联合细胞系统实现，通过"连续吸引子网络"维持一个随运动滑动的空间表征状态。它是认知地图不依赖外部环境线索的内部基础，也是解释为什么动物能在黑暗中精准导航的神经机制。

关键限制：路径整合会**漂移**——小误差随时间积累。动物和人类在无地标情况下长时间路径整合后，位置估计逐渐偏离实际位置。正常导航中，路径整合提供连续性，环境地标提供定期校正，两者互补。

## 关键机制

### 1. 输入信号

路径整合整合三类自身运动信号：
- **前庭信号**：检测头部旋转（半规管）和线性加速度（耳石器），提供方向和加速度信息
- **本体感受**：肢体位置和关节角度，提供运动的身体坐标信号
- **视觉光流**（部分）：地面/环境的视觉流动模式，提供估计速度的视觉线索

### 2. 神经实现：MEC联合细胞

MEC深层的联合细胞（Sargolini等 2006，PMID: 16675704）整合了网格坐标 + 头朝向 + 速度，具备路径整合所需的全部输入。其输出可驱动网格细胞的激活状态更新：
- 当前头朝向（θ）+ 当前速度（v）→ 当前位移矢量
- 位移矢量积分 → 位置更新
- 位置更新 → 相应网格格点激活

### 3. 连续吸引子网络（CAN）模型

McNaughton等2006（PMID: 16858394）的主流计算模型：
- MEC循环兴奋-抑制网络产生一个"活跃凸块"（bump of activity）
- 凸块稳定存在（吸引子动力学），代表当前估计位置
- 速度调制的非对称连接使凸块在速度矢量方向上滑动
- 凸块在六边形格点空间中的位置对应当前路径整合估计

### 4. 漂移与锚定

**漂移的来源**：运动信号噪声、神经计算中的小误差、积分过程中的模型不确定性  
**锚定机制**：环境地标（视觉、嗅觉、触觉）激活相关记忆，将网格/场所细胞的激活重置到环境熟悉位置，修正漂移  
**结果**：路径整合的最优使用策略是"地标之间用路径整合，到达地标后重新校准"
