# 睡眠纺锤波 (Sleep Spindles)

> **一句话定义**：睡眠纺锤波是 NREM 睡眠期间由丘脑网状核（TRN）和丘脑皮层回路产生的 10–15 Hz 振荡爆发（持续 0.5–3 秒），在脑电图上呈梭形包络，是慢振荡-纺锤波-涟波三重耦合的关键中间层，协调海马 SWR 信号在皮层的突触强化时机。

## 当前理解

我们现在认为，睡眠纺锤波的主要认知功能是在记忆系统巩固中扮演"协调员"角色：

1. **时序锁定**：纺锤波精确嵌套在新皮层慢振荡（SO）的上行态中，在皮层突触可塑性窗口打开的瞬间，同步各皮层区域进入"接收准备态"。
2. **信号中继放大**：海马 SWR 触发丘脑汇聚核（Reuniens Nucleus）产生纺锤波，后者将信号传至 mPFC，形成 SWR→丘脑纺锤波→皮层纺锤波的因果级联（Basha et al., 2025）。
3. **突触可塑性促进**：纺锤波期间的 Ca²⁺ 涌入可激活 CaMKII 和 CREB，为长期突触增强提供分子条件。

睡眠纺锤波的密度（spindle density）与记忆成绩呈正相关，在人类睡眠研究中已有大量一致性发现。

## 关键机制

- 产生回路：丘脑皮层（TC）细胞与丘脑网状核（TRN）形成振荡回路；TRN 的 GABAergic 抑制反复压制 TC 细胞，产生约 10–15 Hz 的张弛振荡。
- 皮层起搏：新皮层的慢振荡上行态为纺锤波的产生提供去极化背景；皮层慢振荡相位决定纺锤波何时出现。
- 三重耦合：正确时机的纺锤波（嵌套于 SO 上行态 + 与 SWR 同步）才能有效促进记忆；时机错开则效果消失（Latchoumane 2017 光遗传验证）。
