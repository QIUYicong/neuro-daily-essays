# 背柱-内侧丘系通路（Dorsal Column-Medial Lemniscus Pathway）

> **一句话定义**：精细触觉、振动觉和意识性本体感觉从皮肤到大脑的主要三级中继通路：脊髓背柱（同侧上行）→ 延髓薄束核/楔束核（换元）→ 内侧丘系（交叉）→ 丘脑 VPL → 初级体感皮层 S1。

## 当前理解

我们现在认为，背柱-内侧丘系（DCML）通路是精细触觉信号传导的高速公路：大直径 Aβ 传入纤维从四类皮肤机械感受器经过三级神经元（脊髓→延髓→丘脑→皮层）将精确的躯体位置信息和时序信息传递到 S1。全程保持**躯体拓扑（somatotopy）**：腿部信号始终位于通路内侧（薄束/薄束核），上肢信号始终位于外侧（楔束/楔束核），这种组织一直保持到丘脑和 S1。

损伤背柱后，患者可保留粗糙触觉和痛温觉（由脊髓丘脑束独立传导），但两点辨别、振动觉和感知肢体位置的能力严重受损。

## 关键机制

### 三级中继结构

```
第一级神经元（DRG）
皮肤 Aβ 传入 → 脊髓背角 → 背柱同侧上行
  - 腿/腰：薄束（gracile fasciculus，内侧）
  - 上肢/躯干：楔束（cuneate fasciculus，外侧）

第二级神经元（延髓背柱核）
薄束核（gracile nucleus）→ 楔束核（cuneate nucleus）
轴突交叉：形成内侧丘系（medial lemniscus）
内侧丘系上行时旋转 90°（躯体拓扑保持）

第三级神经元（丘脑 VPL → S1）
丘脑腹后外侧核（VPL）
→ 内囊后肢 → 初级体感皮层 S1
```

### 与脊髓丘脑束的对比

| 维度 | 背柱-内侧丘系通路 | 脊髓丘脑束（前外侧系统） |
|------|----------------|------------------|
| 传导信息 | 精细触觉/振动/两点辨别/本体感觉 | 痛觉/温度觉/粗触觉 |
| 换元位置 | 延髓（背柱核） | 脊髓背角（对侧换元立即上行） |
| 交叉时间 | 延髓水平交叉 | 脊髓当节立即交叉 |
| 损伤症状 | 同侧精细触觉丧失（对侧痛温保留）| 对侧痛温丧失（同侧精细触觉保留）→ 分离性感觉障碍 |
