# 循环神经网络 (Recurrent Neural Network, RNN)

> **一句话定义**：一类神经元之间存在反馈环路（当前状态会持续影响未来状态）的网络，其计算能力来自内部状态随时间的连续动力学演化，而非单次前馈变换；在神经科学中，训练好完成特定任务的 RNN 被广泛用作理解生物神经环路群体动力学的可分析代理模型。

## 当前理解

我们现在认为，循环神经网络是连接"任务的抽象计算要求"与"生物神经环路具体动力学实现"最有效的桥梁工具之一。它的核心逻辑是：只规定网络必须完成什么任务（例如"依情境正确整合两路证据"），不规定网络内部该用什么策略解决——网络通过梯度下降自己找到一个解，这个解本身随后可以被当作一个具体、可证伪的计算假说，拿到真实神经数据里检验。

这套方法论最著名的成功案例，是 Mante、Sussillo、Shenoy 与 Newsome（2013，*Nature*）证明的：一个仅被训练"给出正确选择"的循环网络，会自发学出与猕猴前额叶皮层群体活动高度吻合的动力学结构——一条线吸引子加一个情境依赖的选择向量。这一发现之所以重要，不在于"AI 模仿了大脑"，而在于两个完全独立的优化过程（演化 vs 反向传播）在面对同一类数学结构的问题时，被"推"向了同一种几何解，提示计算问题本身的结构在相当程度上决定了可行解的形状。

但这种"表面吻合"的证据力度是有边界的：2019 年 Maheswaranathan 等人的大规模比较研究表明，不同架构的 RNN 学到的解在**拓扑结构**层面高度普适（有几个不动点、如何连接），但在**具体几何形状**层面却是"个体化的"——依赖于架构选择本身。这意味着，比较 RNN 与生物数据时，拓扑结构的吻合是比精确几何形状吻合更可信的证据。

## 关键机制

### 1. 为什么"循环"是必要的：混合选择性与 XOR 问题

Rigotti、Ben Dayan Rubin、Wang 与 Fusi（2010）用理论证明说明：任何要求"同一输入在不同情境下产生相反输出"的任务（本质是 XOR 型非线性可分问题），纯前馈、单变量选择性的神经元表征在原理上无法求解——必须依赖对多个变量组合敏感的"混合选择性"神经元，而混合选择性天然要求循环连接：只有存在反馈环路，网络才能持续携带"当前处于哪个情境"这类内部状态变量，并让它与瞬时输入非线性地组合。值得注意的是，即使是完全随机连接、未经任何训练的循环网络，也会自发表现出解决此类任务所需维度的混合选择性——提示这种表征资源某种程度上是"廉价"的，学习过程更像是"筛选"而非"从零构建"。

### 2. 群体动力学视角：从单神经元调谐曲线到状态空间轨迹

与其把每个神经元当作独立的变量传感器，动力系统视角把某一时刻整个记录到的神经元群体活动看作高维状态空间中的一个点；随时间推移，这个点画出一条轨迹。Vyas、Golub、Sussillo 与 Shenoy（2020，*Annu Rev Neurosci*）的系统综述指出，这一视角能够解释"表面上极其复杂的单神经元反应"，其根源常常是相对简单的群体层面几何结构（旋转动力学、不动点、null/potent 子空间分解）。这一框架已被用于统一解释运动皮层准备/执行阶段活动、前额叶情境依赖决策、以及无需专用时钟元件、仅靠递归动力学涌现出的内在计时表征（见 [[population-clock]]）。

### 3. 线吸引子与选择向量：一个具体机制案例

在 Mante 2013 的情境依赖决策任务中，训练好的 RNN 呈现出两条线吸引子（每种情境一条），末端各有一个真正稳定的吸引子对应两个选择；决定输入能否有效推动状态沿选择轴移动的，是一个与情境相关、会整体切换方向的"选择向量"——无关输入不是被过滤掉，而是被投影到与选择轴正交、对最终决策没有净效应的方向。这与早期"感觉输入在到达决策阶段前就被过滤"的假说相反：选择发生在与证据累积同一套循环回路内部。

### 4. 普适性与个体性：一个重要的方法论边界

Maheswaranathan 等人（2019，NeurIPS）系统比较了近三千个不同架构（Vanilla RNN/LSTM/GRU/UGRNN）在相同任务上训练出的解，发现**不动点拓扑结构**跨架构高度普适，但**表征几何细节**因架构而异，部分未训练网络的几何相似度甚至高于跨架构的已训练网络对。这为"RNN 与生物数据几何相似即证明生物学相关性"这类论证设定了重要的置信度上限。

## 未解问题

- Q-rnn-01（高优先级）：线吸引子+选择向量框架能否推广到两个以上情境、两个以上证据来源的更高维决策任务？选择向量数量是否随情境数线性增长？
- Q-rnn-02（中优先级）：前额叶如何稳定维持"情境"这一内部变量本身、不被感觉噪声冲刷掉——是否需要额外的连续吸引子机制？
- Q-rnn-03（高优先级）：Maheswaranathan 2019 的普适性/个体性框架尚未直接应用于真实生物神经数据——如果对同一任务下多只动物的神经群体数据做同样的拓扑 vs 几何分析，个体动物之间的"个体性"差异会有多大？
- Q-rnn-04（中优先级）：当 RNN 在多任务（而非单任务）条件下训练时会涌现组合性子结构，这种"任务丰富度驱动的计算基元"假说，能否解释大脑必须同时处理成百上千项任务这一约束下涌现的电路结构？
