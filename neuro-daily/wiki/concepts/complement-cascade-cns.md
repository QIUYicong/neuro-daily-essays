# 补体级联（CNS 中的突触功能）(Complement Cascade in CNS Synaptic Function)

> **一句话定义**：经典补体级联（C1q→C4→C3b）在 CNS 中被神经元和星形胶质细胞-神经元轴挪用为突触剪枝的分子标记系统：发育期在弱突触上沉积 C3b，微胶质细胞通过 CR3 识别并吞噬；在阿尔茨海默病中被 Aβ 低聚体病理性重激活，导致斑块出现前的早期突触丢失。

## 当前理解

我们现在认为，补体系统——免疫系统的一套古老级联酶促反应——在 CNS 中有一个迄今未被完全认识的非免疫功能：充当突触剪枝的分子标记系统。补体蛋白 C1q 由发育期神经元（受星形胶质细胞 TGF-β 上调）产生，在出生后关键期突触上积累，启动 C3b 的级联生成和沉积。沉积了 C3b 的突触被小胶质细胞通过 CR3 识别和吞噬，从而被从回路中删除。

这套机制与神经活动耦合：活跃突触上的"别吃我"信号（CD47）抑制吞噬，而沉默突触则积累 C3b 而未被 CD47 保护，优先被吞噬。发育结束后，CNS 中的补体活性大幅下降；但在神经退行性疾病（AD 等）和可能的精神分裂症青春期加速剪枝期，补体可被病理信号重新激活。

**2026-07-15 更新**：一项新研究（Crowley、Hong 等 2026，*Science*）提出了一个此前未被认真考虑的可能性——C1q 在 CNS 突触上的沉积，可能部分依赖它在外周免疫系统里最经典的功能：识别抗体。这项研究报告称，人为提高成年小鼠海马穿通通路的活动（而非发育期经典模型里的"压低"活动）同样会触发局部 C1q 依赖的突触丢失，并观察到活动依赖性聚集在脑膜的 B 淋巴细胞谱系细胞、以及与突触 C1q 共定位的 IgM。如果这一机制成立，Q-complement-01 提出的"C1q 结合的具体配体是什么"这一问题，会得到一个具体候选答案：不是突触膜本身的某种特殊分子，而是抗体的 Fc 段——C1q 认的仍然是它在外周免疫系统里最擅长认的东西，只是"挑出哪个突触"这一步由抗体（及背后决定其特异性和分泌时机的 B 细胞）完成。**但这项研究目前只有结构化摘要可读，全文因访问受限未能获取，且已在预印本阶段受到具体的同行公开质疑**（详见下方"关键证据"与本页"未解问题"更新，完整讨论见文章 [[2026-07-15-antibody-c1q-adult-synapse-pruning]]）。本页因此将"抗体协同识别"标记为一条独立于经典发育机制的 emerging（新兴、待验证）路径，不改变已确立核心机制的 established 状态。

## 关键机制

### 经典补体通路（CNS 中的发育版本）

**信号来源（CNS 特异）**：
- C1q：发育期神经元自身产生（非外周血液来源）
- 星形胶质细胞 → 分泌 TGF-β → 上调邻近神经元的 C1q 表达
- 这构成了星形胶质细胞→神经元→补体→微胶质的跨细胞信号轴

**C1q 启动**：
1. C1q 结合突触膜上的配体（具体配体在 CNS 中仍不完全清楚）
2. C1q 构象改变 → 激活 C1r→C1s 蛋白酶
3. C1s 裂解 C4 → C4b（沉积于膜表面）和 C4a（游离）
4. C4b 结合 C2 → C3 转化酶（C4bC2a）

**C3b 形成（调理素化）**：
5. C3 转化酶裂解 C3 → C3a（促炎，游离）+ C3b（调理素，共价结合膜）
6. C3b 与膜表面共价结合，形成稳定的突触标记
7. C3b 可进一步形成替代途径 C3 转化酶（C3bBb），放大信号

**微胶质识别与吞噬**：
8. 微胶质 CR3（αM/CD11b-CD18 异二聚体）识别 C3b（特别是 iC3b）
9. CR3 激活下游吞噬信号
10. 吞噬体形成，包裹突触末梢，与溶酶体融合降解

### 活动依赖调节（与 CD47 的双向博弈）

- 活跃突触：高 CD47 → 与 SIRPα 结合 → 磷酸酶 SHP-1 抑制吞噬体形成 → 受保护
- 沉默突触：低 CD47 + C3b 沉积 → 吞噬信号净优势 → 优先被删除

### 抗体作为可能的活动信息翻译者（2026-07-15 新增，emerging，未经独立重复）

Crowley、Hong 等（2026）提出的候选机制链：局部神经元过度活跃 → 未知信号促使脑膜区域 B 淋巴细胞谱系细胞（含抗体分泌细胞）活动依赖性聚集、分泌 IgM → IgM 结合突触相关抗原 → C1q 经其识别抗体 Fc 段的经典功能被募集到该位点 → 继续走已知的 C4→C3b 级联 → 微胶质 CR3 识别吞噬（这一步与经典发育机制原理相同）。这条链路最薄弱、也是最关键的一环——"神经元活动如何转化为局部特异性抗体募集的信号"——目前完全未知，且该研究报告的具体统计细节因全文访问受限未能核实。免疫学者 Jonathan Edwards 在预印本讨论平台上公开质疑该研究可能是"模型 artefact"，具体指出产生可溶 IgM 通常需要浆细胞而非任意 B 系细胞，与已知人类脑-B 细胞生物学存在张力。本页将此路径标记为独立于经典机制的候选补充，其存在与否需要独立重复验证。

### 发育期与成年期的表达差异

| 时期 | C1q/C3 水平 | 功能状态 |
|------|------------|---------|
| 胚胎期 | 低 | 不参与突触功能 |
| 出生后关键期（P2–P21，鼠） | 高（突触局部） | 主动剪枝 |
| 成年正常期 | 低（但可检测） | 低水平维护？尚不清楚 |
| AD 等疾病 | 病理性升高（突触局部） | 过度标记→过度剪枝 |
