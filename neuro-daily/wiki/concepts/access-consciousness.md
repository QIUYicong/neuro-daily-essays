# 通达意识 (Access Consciousness, A-consciousness)

> **一句话定义**：Ned Block 1995 年提出的区分：通达意识（A-consciousness）指信息在认知系统中可被灵活使用、可以报告、可以驱动推理和行动的状态，与现象意识（P-consciousness，主观体验的原始感觉质）在概念上相区别。

## 当前理解

**Block 的两种意识区分**（1995年）是当代意识研究方法论的核心概念区分：

- **通达意识（A-consciousness）**：一个心理表征是 A-conscious 的，当且仅当它（1）可被推理系统使用，（2）可以直接控制行为（包括报告行为），（3）可被语言报告。本质上是"信息对整个认知系统可用"。
- **现象意识（P-consciousness）**：主观的、内在的感觉质（qualia）——看到红色"是什么感觉"（what it's like）、听到钢琴声"是什么感觉"。这是 Chalmers 所称的"意识难问题"的所指。

**为什么这个区分重要**：
1. **方法论**：所有需要被试"报告"体验的实验，测量的是 A-consciousness 的神经基础，而非（必然是）P-consciousness 的神经基础
2. **理论争议**：HOT 理论认为 A-consciousness 和 P-consciousness 在神经机制上不可分（P 需要 A）；RPT 和某些一阶理论认为 P-consciousness 可以存在而没有 A-consciousness（即有主观体验但不可报告）
3. **溢出争议（Overflow Debate）**：Block 主张现象意识可以"溢出"通达意识——即我们可以体验到比我们能报告的更多内容

**神经科学相关**：
- P3b 是 A-consciousness 的 ERP 关联物（Cohen 2020，PMID:32409620），因为它在无报告条件下消失
- GWT 的点燃机制描述的是 A-consciousness（信息全局可用）
- HOT 的高阶表征是 A-consciousness 的必要条件
- VAN（Pitts 2014）可能是比 A-consciousness 更接近 P-consciousness 的 NCC，因为它在无报告时仍存在

**溢出争议的现状（2026 年）**：
- Block 阵营：Sperling 实验和改良版"部分报告"实验提示，图标记忆中的视觉体验多于被试能报告的内容 → P-consciousness > A-consciousness
- 反驳（Kouider 等）：这些实验无法排除"被试有更多可报告但没有报告"的可能；P-consciousness 可能本来就不超过 A-consciousness

我们现在认为，A-consciousness 与 P-consciousness 的区分是重要的概念工具，但在实验上彻底分离两者仍然是开放问题。

## 关键机制

### A-consciousness 的计算定义

A-consciousness 本质上是"信息的可通达性"：
1. **工作记忆保持**：信息进入工作记忆缓冲区
2. **全局广播**（GWT 框架）：信息通过前额顶叶广播系统向全脑分发
3. **报告能力**：语言系统可以访问该信息并产生报告

### 与 P-consciousness 的神经关系（争议中）

```
观点 A（HOT/GWT）：P = A + 高阶表征/全局广播
  P-consciousness 必须依赖 A-consciousness 的神经基础
  没有可通达的信息就没有现象体验

观点 B（RPT/FOT）：P 先于 A 存在，A 是可选的附加物
  后方皮层递归 → P-consciousness（不需要全局广播）
  全局广播 → A-consciousness（报告等高级功能）
  两者解离实验是核心证据场
```

## 未解问题

- **Q-ac-01**（高优先级）：P-consciousness 是否真的可以在没有 A-consciousness 的情况下存在（"溢出"）？或者所有现象体验都必然包含一定程度的认知通达性？这是区分 HOT/GWT 与 RPT/FOT 的核心实验问题，但目前没有确定答案。
