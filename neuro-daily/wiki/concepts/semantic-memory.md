# 语义记忆 (Semantic Memory)

> **一句话定义**：语义记忆是对世界的概念性和事实性知识（"苹果是水果"、"巴黎在法国"），其神经基础是分布-整合双层结构：感觉运动皮层提供模态特异的"辐条"，双侧颞叶前部（ATL）作为跨模态"枢纽"整合出概念的统一表征。

## 当前理解

我们现在认为，语义记忆（Tulving 1972的原始定义：关于世界的一般知识，不依赖于个人经历记忆）在大脑中以**枢纽-辐条（hub-and-spoke）模型**实现（Lambon Ralph 2013）：

**辐条层（Spokes）**：感觉运动皮层各处存储模态特异的概念属性——
- 视觉辐条（腹侧视觉流 / IT皮层）：形状、颜色、运动
- 听觉辐条（听觉皮层）：声音属性
- 体感/运动辐条（体感皮层、前运动皮层）：触觉特征、操作程序
- 语言辐条（颞上回、Broca区）：词汇标签

**枢纽层（Hub）**：双侧颞叶前部（ATL，尤其颞极BA38及腹内侧ATL）将辐条信号聚合成跨模态的统一概念表征，使"苹果"的概念无论通过哪种感觉通道触发都能激活相同的跨模态内容。

语义记忆与情景记忆（依赖海马的事件记忆）在功能和神经底层上均可解离：语义痴呆患者（ATL萎缩）早期语义记忆严重受损，而情景记忆相对保留。互补学习系统理论（CLS）将二者理解为新皮层长时程权重与海马快速绑定的互补分工。

**语义控制层**：语义认知还需要左侧LIFG（BA45）和后颞中回（pMTG）组成的控制系统，根据上下文动态调控哪些语义关联被激活（Jefferies 2013）。

## 关键机制

**1. Hebbian学习建立辐条**：儿童反复接触苹果时，视觉皮层（红色圆形）、听觉皮层（咬苹果声）、味觉区等同时激活，通过Hebbian强化形成特征集成的细胞集成体。

**2. ATL跨模态整合**：ATL神经元接受来自多感觉通道的信号，其解剖位置（下纵束、钩束、IFOF的汇聚点）使其天然成为多感觉信号的整合点。

**3. 语义控制**：LIFG/pMTG根据任务需求调控ATL-辐条网络的激活权重，实现上下文依赖的灵活语义激活。
