# 分布式运动控制 (Distributed Motor Control)

> **一句话定义**：运动指令的生成与执行不依赖单一中央控制节点，而是分散于多个层级：局部感觉-运动回路优先负责执行（延迟最小化），中间层协调跨体节整合，高级脑区提供监督性调节与学习更新——BANC 连接组（2026）在果蝇完整中枢神经系统层面首次给出了这一架构的完整结构证明。

---

## 当前理解

传统的"中央指挥"模型（centralized command model）将运动控制描述为从大脑皮层→脊髓→肌肉的单向层级：皮层发出命令，脊髓中继，肌肉执行。这一模型在教学上简洁，但被越来越多的结构和功能证据质疑。

**分布式运动控制**（Distributed Motor Control）是一种替代框架，其核心命题是：

1. **局部闭合回路是第一执行层**：执行细胞（运动神经元、内脏传出神经元）的最强输入来自同一体节/同一体部的感觉细胞，形成快速局部反馈回路。大脑的长程下行信号，系统弱于这些局部信号。

2. **中间层协调跨模块整合**：连接大脑与脊髓/腹侧神经索的中间层神经元（下行神经元 DNs、上行神经元 ANs）不是单向命令线，而是在两端都有实质突触输出的双向协调节点，负责产生协调的整体行为（如行走时各腿的节律同步）。

3. **高级脑区提供监督性控制**：大脑的高级结构（果蝇的中央复合体、灵长类的运动皮层）主要设定行为目标（方向、速度、精度要求），而不是逐步骤指定每块肌肉的收缩时序。

**关键证据**：BANC（Bates et al. 2026，PMID:40766407，PMC12324551，开放全文）基于成体果蝇完整中枢神经系统连接组（~160,000个神经元，~10^8突触），对约240亿对神经元计算线性影响力得分，系统地证明了"局部优先"原则：执行细胞的最强输入来自同一体节的感觉细胞，长程连接权重系统弱于局部连接。

**当前地位**：在果蝇中，分布式运动控制的**结构基础**已被 BANC 高置信度建立（已建立接线图）。该原则是否适用于脊椎动物（特别是人类灵长类），当前只有概念性类比支持，缺乏接线图层面的直接证据——仍是 `emerging` 状态，置信度 `medium`。

## 关键机制

### 层级架构

```
层级 3：高级脑区（监督层）
  中央复合体（果蝇）/ 运动皮层（灵长类）
  → 设定行为目标，处理导航/决策，在需要时更新策略
  → 对执行细胞的直接影响力弱

层级 2：中间协调层（整合层）
  下行神经元（DNs，~1,300个，脑→VNC）
  上行神经元（ANs，~1,900个，VNC→脑）
  → 在脑和 VNC 两端都有突触输出（双向协调）
  → 15个行为超群集（威胁、进食、飞行、行走、繁殖等）

层级 1：局部感觉-运动回路（执行层）
  同体节感觉细胞 ⟷ 运动神经元 / 内脏传出细胞
  → 最强影响力来源；延迟最短；鲁棒性最高
```

### 局部优先原则的逻辑

局部感觉-运动回路的优先性有明确的计算逻辑：

- **延迟最小化**：局部回路传导距离短，可以在毫秒级内响应感觉扰动，不需要等待信号往返大脑的来回时延（在大型动物中此延迟尤为显著）
- **鲁棒性**：局部回路的功能不依赖于上级通路的完整性，局部损伤后部分功能可保留
- **可扩展性**：通过模块化局部回路 + 中间层协调，系统可以扩展到大型身体，而不需要中央计算单元随比例增大

### 与"中央指挥"模型的主要差异

| 维度 | 中央指挥模型 | 分布式控制模型 |
|------|------------|--------------|
| 执行层 | 脊髓是命令中继 | 脊髓/VNC 是主动执行层 |
| 下行信号 | 命令流（step-by-step指令） | 调制/监督（目标+偏置） |
| 上行信号 | 纯粹状态反馈 | 双向协调信号 |
| 高级脑区 | 执行控制 | 监督控制 |
| 损伤响应 | 局部损伤破坏全局 | 局部损伤后部分功能可保留 |

## 未解问题

- **Q-dmc-01**（高优先级）：BANC 揭示的局部优先原则在脊椎动物（特别是灵长类）中是否有类似的接线图结构支持？人类脊髓固有神经元网络（propriospinal neurons）是否扮演类似 DNs/ANs 的中间协调角色？需要脊髓连接组学（尚未完成）验证。

- **Q-dmc-02**（中优先级）：分布式运动控制的局部回路能否在脊髓损伤后自主重组？脊髓损伤后观察到的一些功能恢复是否源于局部回路的自适应重配置？这对神经修复策略（脊髓刺激、外骨骼+BCI 组合）有何启示？

- **Q-dmc-03**（中优先级）：BANC 的影响力评分（基于线性动力学近似）是否能被功能实验验证？哪些局部感觉-运动回路在光遗传学实验中可以被精确激活/抑制，并与 BANC 的结构预测对照？
