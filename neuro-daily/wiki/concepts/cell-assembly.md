# 细胞集群 (Cell Assembly)

> **一句话定义**：因共同激发而通过赫布 LTP 相互高度连接的神经元集合；当集群任一子集被激活时，增强的循环连接将激活传播至全体成员，实现联想记忆的内容可寻址检索（即模式补全）。

## 当前理解

我们现在认为，赫布（Hebb, 1949）提出的细胞集群假说是目前神经科学中最受广泛支持的记忆网络理论之一，并已在多个实验层面获得直接验证。

**细胞集群的核心逻辑**：学习时一批神经元共同激发，相互之间的突触通过 NMDA 受体依赖的 LTP 得到增强；此后，即使只有部分输入线索，循环连接将激活从"部分成员"传播到"全体成员"，完成联想检索。

**在海马 CA3 的实现**：CA3 区是细胞集群最明确的解剖底座：
- 每个 CA3 锥体细胞接受约 12,000 个来自其他 CA3 细胞的循环侧支突触（vs 来自齿状回苔状纤维的 ~50 个），循环输入量约为外部输入的 240 倍（Le Duigou et al., 2014，PMID:24409118）
- 这一极度递归的结构满足 Hopfield 型吸引子网络的全部结构前提
- Rolls（2013，PMID:24198767）估算大鼠 CA3 可存储约 36,000 个独立的细胞集群记忆

**核心分子因果证据**：Nakazawa et al.（2002，PMID:12040087）的 CA3 特异性 NMDA 受体基因敲除实验证明，CA3 循环突触的 LTP 对**从部分线索恢复完整记忆**（模式补全）是必要条件，而对有完整线索时的编码/提取则非必要——精确定位了细胞集群的联想检索功能。

**时间组织**：Buzsáki（2010，PMID:21040841）的"神经语法"框架揭示了集群的时间结构：
- **基本集群单元**（gamma 周期，~20–30 ms）：约 1% CA3/CA1 细胞（150–300 个）同步激发
- **相位序列**（theta 周期，~120–150 ms）：7±2 个连续基本集群单元构成一个"神经词"
- **Sharp-Wave Ripple**：离线期以 ~20× 速度压缩重播集群序列，驱动海马→皮层记忆固结

**与印迹细胞的关系**：印迹细胞（Josselyn & Tonegawa, 2020，PMID:31896692）是集群的**节点**，强化的循环 LTP 突触是集群的**边**；印迹细胞实验证明了节点存在（充分性），CA3-NMDAR 实验证明了边（循环 LTP 网络）对联想检索的必要性。

## 关键机制

### 1. 集群的组装（编码阶段）

**步骤 1 — LTP 写入**：共同激发的 CA3 细胞间，循环突触处 NMDA 受体检测到 Hebb 型巧合（突触前谷氨酸 + 突触后去极化）→ Ca²⁺ 内流 → CaMKII → AMPA 受体插入 → 循环突触 LTP。共激发的细胞对之间权重升高。

**步骤 2 — STDP 雕刻方向性**：STDP 在 CA3 循环突触上施加时序选择性：前先后随（pre→post, <30 ms）→ LTP；后先前随 → LTD。结果：集群不只是"权重增高的细胞集合"，而是有内在时序方向性的**相位序列**（Hebb 原初设想的实现）。

**步骤 3 — BCM/元可塑性防崩溃**：BCM 滑动阈值 θ_M 随细胞整体活动水平升高而升高，防止所有突触无差别增强（正反馈失控）。确保集群稀疏正交：不同事件的集群彼此高度独立。

### 2. 集群的激活（检索阶段）

**模式补全过程**：部分输入线索激活集群中一部分成员 → 增强的循环 LTP 突触将激活传播给其他成员 → 整个集群被重新激活 → 下游读出神经元产生响应 = 联想记忆被提取。

**吸引子动力学（Hopfield 框架）**：CA3 循环网络的状态空间中，每个完整存储集群对应一个能量最小值（吸引子盆地）。给定部分线索（高维空间中一个"扭曲"状态），网络沿能量梯度下降，收敛到最近的吸引子（完整集群），实现自修正检索。

### 3. 集群的时间组织（gamma / theta 嵌套）

Buzsáki（2010）提出的神经语法层级：

| 层级 | 时间尺度 | 内容 | 振荡 |
|------|---------|------|------|
| 基本集群单元 | 20–30 ms | ~150–300 个细胞同步激发 | Gamma (~40–80 Hz) |
| 神经词 (neural word) | 120–150 ms | 7±2 个连续基本集群单元 | Theta (4–12 Hz) |
| 神经句 | 秒级 | 多个神经词的序列 | Theta/行为节律 |
| 离线重播 | ms (压缩) | ~20× 时间压缩的序列重播 | SWR (140–200 Hz) |

**读出神经元**（Reader neuron）是理解集群功能的关键概念：只有当上游集群成员在读出神经元的时间常数（τ ~ 10–30 ms）内协同激发，读出神经元才产生响应。集群的"意义"由其能激活哪些读出神经元来定义。

### 4. 苔状纤维的"去整合"功能（防干扰）

齿状回（DG）→ CA3 的苔状纤维（~50 个/CA3 细胞，但每个突触极为强大，称为"detonator synapses"）在新记忆编码时发挥关键作用：强制 CA3 进入由 DG 输入决定的**新的随机激活模式**，防止新记忆被已存储的旧吸引子"劫持"（与 LTP 引导的集群形成协同工作）。

## 连接

- [[ltp]] — CA3 循环突触 LTP 是集群形成的突触机制；集群 = 一批循环 LTP 增强的细胞对
- [[stdp]] — STDP 在集群内部雕刻时序方向性；前先后随规则使集群具有有向相位序列
- [[hebbian-learning]] — 细胞集群是赫布规则从单突触尺度涌现到网络尺度的结果；集群组装是赫布规则的网络层面实现
- [[pattern-completion]] — 细胞集群的核心功能：从部分线索通过循环激活恢复完整集群状态
- [[attractor-network]] — CA3 细胞集群在数学上对应 Hopfield 型吸引子；吸引子盆地 = 存储的集群
- [[engram-cells]] — 印迹细胞是集群的节点（哪些细胞）；循环 LTP 是集群的边（如何连接）
- [[sharp-wave-ripples]] — SWR 期间集群以 ~20× 压缩速度重播，驱动海马→皮层固结
- [[theta-oscillations]] — Theta 振荡组织集群序列（相位序列 = Hebb 原初设想）；7±2 个 gamma 单元/theta 周期
- [[hippocampal-circuit]] — CA3 循环侧支是细胞集群的解剖底座；DG-CA3-CA1 三突触回路提供输入/输出
- [[nmda-receptor]] — NMDA 受体是循环突触 LTP（集群写入）的分子巧合检测器
- [[bcm-rule]] — BCM 滑动阈值防止集群无差别扩张（正反馈失控）；保证集群间正交性
- [[metaplasticity]] — 元可塑性是 BCM 规则的上层调控；维持集群稀疏性的网络层机制
- [[place-cell]] — 场所细胞是空间记忆集群（每个场所场 = 一个活跃的场所细胞集群）的主要成员
- [[btsp]] — BTSP（行为时间尺度突触可塑性）可能是 CA1 场所细胞集群快速单次写入的机制（CA3 是否有类似机制尚待研究）
