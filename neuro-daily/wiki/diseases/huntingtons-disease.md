# 亨廷顿病 (Huntington's Disease)

> **一句话定义**：HTT基因（4p16.3）CAG重复≥40导致polyglutamine展开的mutant huntingtin蛋白通过四重协同机制——皮层BDNF供给中断、REST入核引发转录失调、CBP/PGC-1α轴损伤线粒体生物合成、NR2B富集NMDA受体在谷氨酸清除障碍下慢性过激活——选择性摧毁几乎完全依赖皮质营养支持的纹状体中型多棘神经元（MSN），是常染色体显性单基因神经退行性疾病的最精确研究模型之一。

## 当前理解

我们现在认为，亨廷顿病（HD）的核心破坏性并不来自一种单一的毒性机制，而是来自四种相互叠加、相互放大的机制在同一类细胞（纹状体MSN）上的同步收敛。理解这一收敛性是解释纹状体选择性脆弱性的关键。

**遗传基础**：HTT基因编码huntingtin蛋白（3144个氨基酸），CAG重复数的阈值效应高度清晰：≤26正常，27-35中间区（本人不发病），36-39不完全外显，≥40完全外显（必然发病），>60青少年型HD（约占5%，以肌强直为主而非舞蹈症）。常染色体显性遗传，单等位基因突变即致病，发病年龄平均35-40岁，病程约15-20年（PMID:27069383, PMID:28817209）。

**选择性脆弱性的核心**：全身几乎所有细胞均表达mutant huntingtin，但纹状体MSN（占纹状体神经元约95%）最先受到严重打击，晚期>90%退化。这种选择性根植于MSN的四重叠加脆弱性（详见关键机制）。相比之下，纹状体胆碱能中间神经元和PV阳性中间神经元相对幸免，皮层神经元受累但时序晚于纹状体——这种选择性模式为机制假说提供了关键的阴性对照（PMID:11298997）。

**生物标志物与临床分期**：神经退化在临床运动症状出现前15年以上已可通过影像学（尾状核体积缩小）和生物标志物（NfL升高、CSF mHTT可检测）发现（PMID:27069383, PMID:28817209）。这意味着症状前期干预的理论窗口远早于传统的临床症状出现时点。

**治疗现状**：丁苯那嗪（tetrabenazine）和氘丁苯那嗪（deutetrabenazine）——VMAT2抑制剂——FDA批准用于控制舞蹈症，但不改变疾病进程。疾病修饰治疗仍处于临床验证阶段：tominersen（非选择性ASO）的GENERATION-HD1 III期临床因高剂量安全信号（神经损伤生物标志物升高）而暂停；等位基因选择性策略（WVE-003靶向SNP3）是当前最具前景的方向（PMID:41287980, PMID:39027419）。

## 关键机制

### 机制一：polyglutamine展开与N端片段毒性

正常huntingtin N端含有<36个谷氨酰胺的polyQ束，蛋白质稳定折叠。CAG≥40时，polyQ束超过关键长度阈值，倾向于采取β-折叠构象，链间β-折叠形成聚集核心。mHTT的蛋白水解切割（尤其是exon 1来源的N端片段）产生更易聚集的短片段，优先积累于细胞核，形成核内包涵体（IBs）。包涵体的毒性vs保护性仍有争议：当前共识倾向于可溶性mHTT寡聚体是主要毒性物种，IBs可能代表不完全的保护性隔离。野生型huntingtin同时丧失其正常功能：BDNF囊泡轴突运输、REST隔离、抗凋亡（与HIP1竞争）、细胞内囊泡运输支架功能（PMID:37629202）。

### 机制二：BDNF-REST轴断裂与营养供给中断

这是MSN选择性脆弱性最核心的机制，揭示了一种结构性"营养依赖不对称"。

**正常轴**：野生型huntingtin将REST（RE1沉默转录因子）隔离于细胞质 → REST无法入核结合BDNF基因exon II启动子区的RE1元件 → 皮层神经元高水平转录BDNF → 沿皮质纹状体轴突顺行运输至纹状体 → MSN营养支持维持。

**HD中的断裂**：mHTT失去对REST的隔离能力 → REST自由入核 → 占据RE1元件 → 皮层BDNF转录受抑 → 到达纹状体的BDNF减少 → MSN营养供给枯竭。

**为什么是MSN**：纹状体MSN自身BDNF产生水平极低，几乎完全依赖皮质衍生BDNF存活，是一种"单点失效"的营养依赖架构。皮层神经元自身也受REST入核打击，但保有一定的BDNF自产能力，具有缓冲余地（PMID:11408619, PMID:15967378）。

### 机制三：转录失调与线粒体崩溃

REST入核抑制整个REST调控子（数百个神经元特异性基因）。同时，mHTT N端片段物理性捕获CBP（CREB结合蛋白/组蛋白乙酰转移酶）于核内包涵体中 → CBP的HAT活性丧失 → 组蛋白乙酰化水平下降 → CREB依赖靶基因（BDNF、DARPP-32等纹状体特异性标志蛋白）进一步下调。

PGC-1α轴进一步损伤：mHTT阻断CREB/TAF4对PGC-1α启动子的激活 → PGC-1α靶基因（线粒体复合物I、II、IV亚基，抗氧化酶）表达减少 → 线粒体生物合成受损、能量产生减弱 → 细胞对兴奋毒性压力的耐受能力进一步下降，形成负向螺旋（PMID:37629202, PMID:34445070）。

### 机制四：兴奋毒性——谷氨酸慢性压迫

皮质纹状体谷氨酸能投射在HD中成为兴奋毒性的传导路线。HD星形胶质细胞中GLT1（EAAT2）和GLAST（EAAT1）表达下降 → 突触谷氨酸清除受损 → 慢性突触谷氨酸升高 → NMDA受体过激活。

MSN的NMDA受体富含NR2B亚基（相比NR2A具有更慢的去激活动力学），每次激活Ca²⁺内流更持久。在慢性谷氨酸升高环境中，这种受体构成使MSN的Ca²⁺内流量持续高于其他神经元类型。持续Ca²⁺内流 → calpain/磷脂酶A2/nNOS激活 → 线粒体膜通透性转变孔开放 → 细胞色素c释放 → caspase-9/3激活 → 程序性细胞死亡（PMID:37629202, PMID:28817209, PMID:34445070）。

## 连接

- [[basal-ganglia]] — HD导致基底节直接/间接通路的MSN丧失，早期间接通路D2-MSN受损对应舞蹈症的出现
- [[bdnf]] — BDNF-REST轴是HD选择性脆弱性的核心机制；BDNF由皮层提供，MSN无自产能力
- [[parkinsons-disease]] — 对比：PD是黑质多巴胺能神经元选择性死亡（α-syn聚集+CaV1.3脆弱性），HD是纹状体MSN选择性死亡（mHTT+BDNF断供+NR2B兴奋毒性）；两者均是基底节疾病但机制截然不同
- [[polyglutamine-toxicity]] — HD是最典型的polyQ疾病；polyQ展开→N端片段→核内包涵体是共同机制骨架
- [[excitotoxicity]] — NR2B富集+GLT1/GLAST下降使MSN处于慢性兴奋毒性威胁中
- [[nmda-receptor]] — NR2B亚基组成是MSN兴奋毒性选择性脆弱的分子基础
- [[cortical-slow-oscillation]] — 皮质纹状体投射在HD中从"营养高速公路"变为"兴奋毒性传导线路"——同一解剖连接的功能翻转
- [[mitochondrial-dysfunction]] — PGC-1α轴损伤导致线粒体生物合成受损；纹状体特异性Complex II/III缺陷；Ca²⁺缓冲容量降低使mPTP阈值降低——三者共同构成HD的能量代谢崩溃轴
- [[neuroinflammation]] — HD中星形胶质细胞功能障碍（GLT1/GLAST下降）和小胶质细胞激活共同参与神经退化；tominersen高剂量组的安全信号可能部分源于神经炎症
