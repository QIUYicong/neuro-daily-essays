# 语义变异型原发性进行性失语（Semantic Variant PPA, svPPA）

> **一句话定义**：以**双侧前颞叶萎缩**和**腹侧语言流白质退行**为病理基础的神经退行性失语症，选择性破坏语义记忆（所有模态），而产出流畅度、语音和语法相对保留；是腹侧语言流功能最清晰的"自然实验"。

## 当前理解

我们现在认为，语义变异型 PPA（svPPA，也称语义痴呆 semantic dementia）是腹侧语言流损伤的最典型临床模型——一种神经退行性疾病，在相对选择性地破坏腹侧语言流及其皮层靶点（前颞叶）的同时，相对保留背侧语言流（SLF/AF）。

**核心临床表现**：
- **流利语言产出**：语言产出流畅，语法正确（背侧流相对完好）
- **严重语义丧失**：词汇意义、物体知识、面孔识别、概念知识系统性丢失
- **跨模态语义损伤**：无论通过视觉、听觉还是触觉呈现同一概念，患者都无法理解——这是"跨模态"损伤的特征，证明损伤在整合区域（ATL 枢纽），而非模态特异通路
- **相对保留**：外显情节记忆（可以记住今天发生的事）、空间认知、语音意识

**典型早期症状**：
- 无法命名常见物体（不是说出词来，而是不知道词代表什么）
- 专有名词命名障碍先于一般名词（如"爱因斯坦"→"不认识的人"）
- 阅读障碍，特别是不规则词（surface dyslexia：知道字母读法，但看到"yacht"会按照规则拼读而非知道意思）
- 表面失读：理解力丧失，但语音输出流利

**神经病理**：
- 通常（约50-80%）与**TDP-43蛋白病变**（FTLD-TDP-C型）相关
- 灰质：双侧前颞叶萎缩，左侧更早、更重
- 白质：腹侧流选择性退化

**白质特征（DTI）**（Agosta 2010，PMID:19759202；Agosta 2013，PMID:23890877；Bouchard 2019，PMID:31030675）：
- **最严重受损**：左侧 ILF、左侧 UF（下纵束和钩束，腹侧流主体）
- **中等受损**：左侧 IFOF
- **相对保留**：SLF（上纵束），顶额连接
- 这一模式与 nfvPPA 形成鲜明对比（nfvPPA 选择性损伤 SLF/AF，背侧流）

**与非流利变异型 PPA（nfvPPA）的白质双离解**：

| | svPPA | nfvPPA |
|---|---|---|
| 主要损伤白质束 | ILF + UF（腹侧流） | SLF + AF（背侧流） |
| 主要损伤皮层 | 双侧前颞叶 ATL | 左额下回 / 岛叶 |
| 核心缺陷 | 语义记忆 | 语音产出 / 语法 |
| 语言产出 | 流利（空洞） | 非流利（吃力）|

这个双离解是支持双流语言模型最有力的病变证据之一：腹侧流损伤导致选择性语义障碍，背侧流损伤导致选择性产出障碍，精确符合功能分工预测。

**疾病作为知识论工具**：svPPA 之所以重要不只是临床原因，而是因为它是理解正常大脑腹侧流功能的**"减法神经科学"**工具——通过选择性破坏，揭示被破坏结构在正常状态下的贡献。

## 关键机制

```
正常腹侧流：
视觉/听觉输入 → ILF/IFOF → ATL（语义枢纽）→ 语义理解

svPPA 病理：
TDP-43 聚集 → 双侧 ATL 神经元退行 →
  └→ 继发 Wallerian 退变：ILF + UF + IFOF 轴突退化
  └→ 语义网络解体：所有模态输入均无法整合为语义

临床结果：
流利说话（背侧流完整）但不知道词是什么意思（腹侧流断裂）
```
