# 传导性失语症 (Conduction Aphasia)

> **一句话定义**：语言理解基本完整、自发言语流利，但**无法准确重复**听到的词语或句子的失语综合征；经典解释为弓状束（AF）直接段或颞顶界面区（Spt）损伤，导致音韵时序信息无法从颞叶传递到额叶进行发音程序化。

## 当前理解

我们现在认为，传导性失语症是背侧语言流中"音韵时序传输回路"选择性受损的临床表现。

**三个经典特征**（可构成临床诊断）：
1. **语言理解基本完整**：腹侧流（IFOF/UF连接的意义通路）完整，语义理解基本保留
2. **自发言语流利**：Broca区完整，词汇驱动的自发言语流畅
3. **重复严重受损**：听到的词语/句子无法准确重复输出——这是传导性失语的核心标志

**典型表现**：
- 接近错语（literal/phonemic paraphasias）：说错音节，例如将"冰箱"说成"冰...c-箱"
- 频繁的自我纠正尝试（conduite d'approche）：患者知道自己说错了，反复接近正确发音但无法到达
- 命名困难（anomia）：找词困难
- 朗读受损（尤其是无意义词）

**两种损伤位点的争议**：

经典Geschwind模型认为传导性失语源于**弓状束（AF）直接段**损伤，切断颞顶（Spt/pSTG）→额叶（BA44）的音韵传输。但近年VLSM研究（Fridriksson等，PMID:20720112）发现，传导性失语的核心损伤更多与**颞顶界面区（Spt）皮层**功能异常相关，而非单纯的AF白质束损伤。

最可能的整合理解：Spt皮层是音韵短期缓冲（存储），AF直接段是传输通路——两者共同构成完整的音韵工作记忆系统，损伤任意一个都可能产生传导性失语的临床表现，但具体症状谱可能有微小差异。

**DIVA模型框架下的解释**：在DIVA模型中，传导性失语反映了听觉反馈回路（auditory feedback loop）与前馈指令（feedforward command）之间的断联：患者的听觉监控（知道自己说错了）完整，但前馈传输（把正确的音韵时序指令送达发音器官）受损，因此产生"知道错了却无法纠正"的conduite d'approche现象。

## 关键机制

```
正常音韵重复回路：
[听觉输入] → pSTG → Spt（音韵短期缓冲）
                        ↓（弓状束AF直接段）
                    BA44（Broca区）→ 前运动区 → 发音输出

传导性失语（AF或Spt损伤后）：
[听觉输入] → pSTG → Spt ─×─（断路）─×─ BA44
理解完整↑                                    发音（自发言语，来自词汇驱动）仍可↑
                                               但重复所需的"音韵时序传输"失败↓
```

**Conduite d'approche（接近行为）的机制**：
1. 患者尝试重复→输出错误音节
2. 听觉监控（颞叶+监控回路）检测到错误
3. 修正指令生成→但传输通路（AF/Spt）仍然受损
4. 再次输出→再次接近错误
→ 产生多次逼近但无法到达正确发音的连续尝试行为
