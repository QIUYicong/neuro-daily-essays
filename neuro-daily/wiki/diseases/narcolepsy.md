# 发作性睡病（1 型）(Narcolepsy Type 1)

> **一句话定义**：1 型发作性睡病（NT1）是外侧下丘脑食欲素神经元被 T 细胞介导的自身免疫选择性摧毁（85–95% 丢失）的结果，导致睡眠-清醒翻转开关失去稳定器，表现为日间过度嗜睡、情绪触发的猝倒（清醒期 REM 肌张力丧失）、入睡幻觉和睡眠瘫痪。

## 当前理解

我们现在认为，NT1 是最能揭示睡眠-清醒调控回路的"自然实验"之一。疾病的核心是：约 7–9 万个食欲素神经元（位于外侧下丘脑）中的 85–95% 被自身免疫攻击不可逆地消灭，而食欲素神经元的核心功能是作为翻转开关的"稳定器"——不直接启动或终止睡眠，而是增加清醒状态切换到睡眠所需的能量阈值。

失去这个稳定器后：
1. **日间嗜睡**：清醒态随时可能坍塌，尤其在单调环境或餐后
2. **猝倒**：情绪（杏仁核激活）直接触发 REM 肌张力丧失回路，因为食欲素对 vlPAG 的支撑消失
3. **入睡幻觉 / 睡眠瘫痪**：睡眠-REM 边界溶解，REM 特征渗透至半清醒状态

NT1 的病因链条已有相当完整的证据：遗传易感性（HLA-DQB1*06:02，>90% 患者携带）+ 环境触发因素（H1N1 流感或 Pandemrix 疫苗）→ T 细胞介导的自身免疫反应 → 食欲素神经元选择性丢失。但靶抗原的确切身份（prepro-orexin？TBH2？）和免疫攻击的细胞特异性机制（为何比邻的 MCH 神经元幸免）仍是未解谜题。

## 关键机制

### 食欲素缺失与翻转开关失稳

食欲素神经元通过兴奋 vlPAG-LPT（腹外侧导水管周围灰质-外侧桥脑被盖）来抑制 SLD（背外侧桥脑被盖），防止清醒期出现 REM 肌张力丧失。食欲素丢失后，vlPAG-LPT 失去支撑，成为猝倒的结构基础。

### 猝倒的特异性回路

```
正面情绪（大笑、惊喜）
        ↓
   杏仁核激活
        ↓
杏仁核→vlPAG-LPT 抑制投射
        ↓
vlPAG-LPT 失去抑制 SLD 能力
（在食欲素缺失的背景下）
        ↓
SLD 激活 → 延髓抑制脊髓运动神经元
        ↓
   清醒期 REM 肌张力丧失（猝倒）
```

### 自身免疫机制

- **HLA-DQB1*06:02**：MHC class II 等位基因，T 细胞通过此呈递靶抗原；携带者风险增加约 200 倍
- **T 细胞**：CD4+ T 细胞（HLA-DQ0602 限制）和 CD8+ T 细胞对 prepro-orexin 肽段均有反应（Latorre 2018，PMID:30232458）
- **环境触发**：Pandemrix（H1N1 疫苗，AS03 佐剂）→ 儿童 NT1 风险增加 8–12 倍；分子模拟（HA 与 prepro-orexin 序列相似性）是候选机制

## 未解问题

- **Q-narc-01**（高优先级）：NT1 的靶抗原是什么？Prepro-orexin 和 TBH2 均为候选，但靶抗原的确切身份和致病因果性尚未建立。
- **Q-narc-02**（高优先级）：为什么自身免疫攻击如此特异？MCH 神经元（比邻，功能相关）基本幸免；这种细胞特异性的分子基础是 NT1 病因的核心谜题。
- **Q-narc-03**（中优先级）：NT1 是否有治疗窗口？临床发病时 95% 神经元已丢失，但自身免疫攻击可能在更早期开始；早期生物标志物（如血液中 orexin 特异性 T 细胞）是否能在神经元大量丢失前识别高危个体并进行免疫干预？
