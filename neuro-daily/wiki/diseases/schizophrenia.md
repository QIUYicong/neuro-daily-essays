# 精神分裂症 (Schizophrenia)

> **一句话定义**：以正性症状（幻觉、妄想）、负性症状（情感平淡、社会退缩）和持续认知缺陷（工作记忆、执行功能减退）为临床三联征的精神疾病；神经回路机制核心为前额叶 PV+ 中间神经元功能性缄默（GAD67/PV 分子下调而非细胞死亡），导致 γ 振荡生成受损和认知节律崩溃。

## 当前理解

我们现在认为，精神分裂症是一种**回路节律失调的发育性疾病**，而非单纯的神经递质增减。三条汇聚的证据线共同构建这一理解：

1. **分子层的缄默**：精神分裂症患者背外侧前额叶皮层（DLPFC）中，PV+ 快速放电中间神经元的 GAD67（GABA 合成酶）和 PV 蛋白的 mRNA 在约 45% 的细胞中无法检测，而细胞总数基本正常（Hashimoto et al. 2003, PMID:12867516）。细胞没有死，只是失去了"声音"。

2. **回路层的节律崩溃**：PV 细胞通过 PING 机制产生 30–80 Hz 的 γ 振荡。这些振荡是 DLPFC 工作记忆编码的时序骨架。SCZ 患者在执行认知任务时 DLPFC γ 功率持续降低，θ-γ 耦合受损（Gonzalez-Burgos et al. 2015, PMID:25863358）。

3. **上游的 NMDAR 低激活**：NMDA 受体拮抗剂（PCP、氯胺酮）在健康人中可复现精神分裂症的完整症状谱系（Javitt & Zukin 1991, PMID:1654746）；GluN2A 亚基特异性损伤选择性地削弱 PV+ 细胞功能（Hosseini 2025, PMID:40436282）。

这三条证据线汇聚成当前的**γ-PV 假说**：NMDAR 信号不足（遗传性和/或发育性）→ PV 细胞成熟受损（Lhx6/TrkB-BDNF 轴失调）→ GAD67/PV 分子下调 → PING 机制受损 → γ 振荡功率降低 + θ-γ 耦合解体 → 工作记忆和认知功能缺陷。

**症状三联征与机制的对应**：
- **正性症状**（幻觉、妄想）：与多巴胺系统（纹状体 D2 受体过活跃）相关；前额叶 PV 功能缺陷 → 前额叶-皮下抑制减弱 → 纹状体去抑制（顶-下机制）
- **负性症状**（情感平淡、社会退缩）：与前额叶和颞叶的多巴胺活动减少相关；最难治
- **认知症状**（工作记忆、执行功能减退）：与 DLPFC PV-γ 回路损伤直接相关；最影响预后；对多巴胺拮抗剂不敏感

**治疗状态**：多巴胺 D2 拮抗剂有效控制正性症状，但对认知症状几乎无效。新兴靶点：Kv3.1/3.2 调节剂（靶向 PV 细胞复极化能力）；NMDAR 正向变构调制剂（甘氨酸位点）；PNN 重塑（氯氮平机制）。

## 关键机制

### 1. 分子层：GAD67/PV 下调的触发因素

**发育假说**（当前主流）：
- 遗传因素（DISC1、NRG1、GRIN2A 变异）和环境因素（围生期感染、压力）在妊娠和发育早期损伤 MGE 来源的 PV 细胞前体的成熟程序
- Lhx6（MGE 命运转录因子）表达减少 → PV/SST 分化不完全（Volk 2012, PMID:22983435）
- TrkB 信号减弱 → BDNF 介导的 GABAergic 成熟时钟受阻（Hashimoto 2005, PMID:15647480；见 trkb-receptor 页）
- 青春期 PNN 成熟阶段（关键期关闭）某些发育步骤未完成 → 症状在青春晚期出现

**成年期维持机制**（推测）：
- 持续的氧化应激（PV 细胞代谢需求高，易受 ROS 损伤）→ GAD67 转录下调
- NMDAR 信号减弱减少了 PV 细胞的兴奋性驱动 → 活动依赖性 GAD67 下调

### 2. 细胞层：PV 细胞为何选择性脆弱

- 高代谢需求（200–600 Hz 放电，持续产生动作电位）→ 对氧化应激高度敏感
- GluN2A 富含的 NMDAR 在 PV 细胞突触中重要（Hosseini 2025, PMID:40436282）
- 快速放电表型依赖 Kv3.1/3.2 通道（在 SCZ 中表达降低）
- 相比 SST+ 或 VIP+ 细胞，PV 细胞对 NMDAR 信号不足更加敏感

### 3. 回路层：PING 机制的崩溃

PING 机制（Pyramidal-Interneuron Network Gamma）需要：
1. 锥体细胞激活 PV 细胞（AMPAR 主导，NMDAR 辅助）
2. PV 细胞产生 IPSPs 抑制锥体细胞（需要 GAD67 合成充足的 GABA）
3. 锥体细胞从 IPSP 中恢复 → 再次激活 PV 细胞 → 形成振荡回路

当 GAD67 下调，步骤 2 的 IPSP 振幅减小，振荡时序精度下降 → γ 功率降低 + 频率不稳定

### 4. 认知层：工作记忆的时序编码失败

γ 在 DLPFC 工作记忆中以短暂爆发形式（~67 ms）为各个记忆 slot 提供时序框架。θ-γ 嵌套确保不同 slot 在同一 θ 周期的不同相位被激活。当 γ 质量下降：
- 不同记忆项目间的时序分离减弱
- 信息相互干扰，工作记忆容量下降
- 提取错误率上升
