# 递归处理理论 (Recurrent Processing Theory, RPT)

> **一句话定义**：由 Victor Lamme 提出，认为视觉意识的神经基础是大脑后方皮层内的**递归（反馈）处理回路**——前馈扫描可以无意识地提取特征，但只有高级视觉区域向初级视觉皮层发出反馈并形成递归环路之后，感知觉组织（如图像-背景分离）才能出现，意识体验才得以发生。

## 当前理解

递归处理理论（RPT）由荷兰神经科学家 Victor Lamme 及其同事从 1990 年代末开始发展，以灵长类视觉皮层的电生理实验为核心证据基础，是继全局工作空间理论（GWT）和整合信息理论（IIT）之后第三个获得广泛讨论的神经意识理论。

**核心主张**：视觉处理分为两个截然不同的阶段，这两个阶段的计算性质和意识相关性完全不同：

1. **前馈扫描（Feedforward Sweep, FFS）**：视觉刺激呈现后约 50–100 ms 内，神经活动快速平行地从 V1 经过 V2、V4、MT、下颞叶等视觉分级区域传播至全脑。这一过程可以无意识地提取特征（颜色、方向、运动方向、空间频率）、识别物体类别，但**不足以产生任何主观体验**。

2. **递归处理（Recurrent Processing, RP）**：前馈激活高级视觉区域之后，反馈信号从高级区域（如 V4、MT、IT 等）**反向**传播回初级视觉皮层（V1、V2 等），同时 V1 内的水平连接将相邻区域的信息横向整合。这种前向-反向-前向的循环激活构成**递归回路**。RPT 认为，正是这一阶段内的递归处理使感知觉组织（perceptual organization）——最典型的是图像从背景中分离出来——成为可能，并产生意识体验。

**RPT 的意识定义**：意识 = 视觉皮层（尤其是 V1 及早期视觉皮层）内的递归回路达到足够强度和持续时间，使感知觉组织得以完成。注意（attention）和报告（report）都不是意识的必要条件——这是 RPT 与 GWT 最根本的分歧之一。

**最新修订**（Lamme 2018, PMID:30061458）：单纯的递归传导可能不是意识的充分条件（部分递归活动在麻醉状态下仍存在）。"缺失要素"候选是：递归处理通过 **NMDA 受体激活**触发的短暂**网络可塑性**——即递归活动不只是信息在回路中来回传递，而是产生突触权重的短暂改变，形成与当前感知状态相匹配的短期记忆痕迹。

## 关键机制

### 前馈 vs 递归：时间特征

| 时间（ms） | 类型 | 神经活动 | 意识相关性 |
|-----------|------|---------|----------|
| 0–50 | 前馈 | V1 响应初始激活 | 无 |
| 50–100 | 前馈 | V1→V2→V4→IT 传播；特征提取 | 无 |
| 100–160 | 递归启动 | 高级区域向 V1 发出反馈；V1 内水平连接激活 | 开始出现 |
| >160 | 递归成熟 | V1 图像-背景分离信号出现（延迟成分，60-100ms后） | 意识体验 |

### 图像-背景分离信号：RPT 的神经标记

在猕猴实验中，用纹理图形-背景刺激记录 V1 神经元响应：
- **前馈成分**（刺激后 0–60ms）：V1 对图像区域和背景区域的响应基本相同（只反映本地纹理特征）
- **延迟成分**（刺激后 60–100ms+）：清醒猴的 V1 神经元对图像区域的响应**显著增强**，背景区域响应相对抑制——这反映了图像从背景中"突显出来"的感知觉组织信号

这一延迟成分**取决于递归反馈**：
- 麻醉消除它（PMID:9501251）
- 视觉掩蔽消除它（与主观不可见精确对应，PMID:12419127）
- V1 刺激前的神经元同步状态预测它是否出现（PMID:12716948）

### 感知觉组织作为意识的关键运算

Lamme（2020, PMID:32116908）提出四阶段模型：

```
Stage 1（完全不可见）
  特征提取，前馈完成；在麻醉/掩蔽条件下与清醒相同
        ↓
Stage 2（主观不可见）
  部分感知推断，但没有意识体验；仍是前馈主导
        ↓
Stage 3（未注意但可能可见）
  递归处理启动，感知觉组织发生；但注意未专门分配
        ↓
Stage 4（清晰可见 + 被注意 + 可报告）
  全整合意识状态
```

RPT 的关键主张：从 Stage 2 到 Stage 3 的跃迁（递归处理启动）就是意识出现的时刻，不需要等到 Stage 4（注意+报告）。这是 RPT 与 GWT 的根本分歧：GWT 认为没有 Stage 4（全局广播）就没有真正的意识。

## 关键证据

| 主张 | 证据 / 方法 | 来源 | 置信度 |
|------|------------|------|--------|
| 麻醉消除 V1 图像-背景信号（延迟成分），保留前馈响应 | 猕猴清醒 vs 麻醉 V1 单细胞记录 | PMID:9501251（PMC 开放全文） | 高 |
| 视觉掩蔽选择性抑制 V1 图像-背景信号，与主观不可见精确对应 | 猕猴清醒 V1 + 行为（backward masking SOA 调控） | PMID:12419127（摘要） | 中-高 |
| V1 刺激前内部状态（神经元同步性 96% vs 85%）预测感知觉成功 | 猕猴图像检测任务，刺激前 ~100ms V1 记录 | PMID:12716948（PMC 开放全文） | 高 |
| 无报告范式下前额叶激活消失，后方皮层激活维持 | 双目竞争 fMRI 无报告范式；多篇综述 | PMID:26585549（摘要）；PMC5628406（综述全文） | 中（无报告范式方法本身有争议） |
| NREM 睡眠梦境（天然无报告）与后方顶枕高频活动相关（87% 预测准确率），前额叶非必要 | 高密度 EEG + 阶段性唤醒询问；闭环实时预测 | PMID:28394322（PMC5462120，全文） | 高（最接近真无报告条件；Nature Neuroscience） |
| 前馈 TMS（60ms）破坏意识的效果大于递归期 TMS（100ms） | 人类 TMS + 行为，预注册 | PMID:32922860（PMC 开放全文） | 中（挑战简单二分法） |
| 感知觉组织（图像-背景）是意识的关键函数；Stage 3 开始意识 | 四阶段模型整合多个实验室数据 | PMID:32116908（PMC 开放全文） | 中（理论模型，证据拼图） |

## 未解问题

- **Q-rpt-01**（高优先级）：Allen et al. 2020（PMID:32922860）发现早期（前馈期）TMS 破坏意识效果大于晚期（递归期）TMS，如何解释？是"前馈也必要"的证据，还是"TMS 在前馈期引发了异常的递归信号"的人工效应？需要更细粒度的时间-空间 TMS 分离实验
- **Q-rpt-02**（中优先级）：Lamme 提出的"缺失要素"——递归 + NMDA 依赖的网络可塑性——是否有直接实验支持？即：在不影响递归传导的前提下阻断 NMDA 受体，能否选择性消除意识而不影响无意识的递归处理（如 V1 图像-背景信号的某些成分）？
- **Q-rpt-03**（中优先级）：RPT 主要基于视觉系统建立，能否推广到其他感觉模态（听觉、触觉）？A1 中是否有类似麻醉/掩蔽可消除的递归依赖感知组织信号？Kikkert et al.（PMC6621140）在躯体感觉系统有初步支持，但远不如视觉系统完善
