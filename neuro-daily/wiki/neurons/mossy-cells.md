# 苔藓细胞 (Mossy Cells)

> **一句话定义**：齿状回（DG）门状区（hilus）的兴奋性中间神经元，通过接收粒细胞苔藓纤维输入并经由抑制性中间神经元反馈调控粒细胞集合的稀疏程度，是模式分离的重要守门人；创伤应激可导致苔藓细胞失调，进而引发情景区分失败和恐惧泛化。

## 当前理解

我们现在认为，苔藓细胞（mossy cells，又称"苔状细胞"，不同于"苔藓纤维"）是 DG 门状区的兴奋性主细胞（glutamatergic），在功能上位于模式分离回路的反馈控制层。它们并非简单的"中间神经元"，而是通过**双重调控策略**——近距离去抑制（直接激活局部粒细胞）和远距离抑制（通过抑制性 GABA 中间神经元压制远端粒细胞）——精细调节每个情景下活跃的粒细胞集合大小。

苔藓细胞的功能状态对 DG 模式分离的质量有决定性影响：
- **正常状态**：苔藓细胞维持粒细胞集合的"适当稀疏"——足以区分不同情景的不同粒细胞组，但又不至于只有极少粒细胞活跃导致新情景无法编码
- **苔藓细胞受损/受抑制**：粒细胞失去反馈调控 → 更多粒细胞在同一情景中活跃 → 不同情景的粒细胞集合增大且重叠 → 情景间的神经差异性降低 → 情景区分失败

最近的关键进展来自 Jeong et al.（2024，PMID:38527063）：强应激性创伤 → 苔藓细胞受到慢性抑制（机制待确认，可能涉及 LC-NE 轴或 CRF 系统）→ 粒细胞集合重叠增加 → PTSD 恐惧泛化的细胞机制。这是将苔藓细胞直接与创伤精神病理学连接的关键实验，但尚需独立复现。

## 关键机制

### 1. 解剖位置与连接

- **位置**：齿状回门状区（hilus），夹在 DG 的内叶和外叶之间
- **输入**：接受 DG 粒细胞苔藓纤维（mossy fibers）的兴奋性突触（其中一个命名来源）
- **输出**：
  - 直接：轴突投射回同侧和对侧 DG 颗粒细胞层（直接去抑制？）
  - 间接：激活 DG 的抑制性中间神经元（如 PV+ 篮细胞）→ 对粒细胞的反馈抑制
- **远程投射**：苔藓细胞还投射到 CA3 的锥体神经元和中间神经元

### 2. 双重调控功能

苔藓细胞对粒细胞集合的调控具有双向性：
- **局部去抑制**（disinhibition）：抑制局部 GABA 中间神经元 → 允许特定粒细胞继续活跃
- **远程侧抑制**：激活远端 GABA 中间神经元 → 压制其他粒细胞的激活

结果是"胜者为王"的竞争动力学：当一组粒细胞因当前情景的输入获得优势激活，苔藓细胞回路帮助它们稳定活跃，同时压制竞争性的其他粒细胞集合。

### 3. 创伤→苔藓细胞抑制→恐惧泛化链

根据 Jeong et al. 2024：
1. 创伤暴露 → 应激激素/神经递质（NE、CRF 等）释放
2. 苔藓细胞受到慢性抑制（可能通过 α₂ 肾上腺素受体或 CRF 受体）
3. 苔藓细胞活性↓ → 对粒细胞的反馈抑制减弱 → 更多粒细胞活跃
4. 每个情景激活的粒细胞集合变大 → 不同情景的集合重叠度增加
5. 安全情景和危险情景在 DG 层面的神经差异消失 → 无法区分
6. CA3 "补全"触发原有恐惧记忆 → 恐惧在安全情景中泛化
