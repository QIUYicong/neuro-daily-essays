# γ 运动神经元 (Gamma Motor Neuron)

> **一句话定义**：脊髓前角内专门支配肌梭梭内肌纤维极端区（收缩段）的运动神经元，不直接产生力量，而是通过调节梭内纤维张力来主动配置肌梭的感觉灵敏度，在自主运动中维持本体感觉反馈回路的持续工作。

## 当前理解

我们现在认为，γ 运动神经元是运动-感觉整合系统中的隐藏调控层：它既是运动系统的组成（由高级运动中枢控制），又是感觉系统的调制者（改变肌梭的传感特性）。这种双重身份使 γ 系统成为感觉-运动协调的关键节点。

**核心功能**：α-γ 协同激活。当大脑发出运动指令时，α 和 γ 运动神经元通常同步激活——α 神经元驱动梭外肌纤维收缩产生力量，γ 神经元驱动梭内纤维极端区同步缩短，防止肌梭在肌肉缩短时"沉默"（脱敏），使 Ia/II 型传入在整个运动过程中持续工作。

**分类**：分为动态 γ（γd，支配 bag1 纤维，放大速度灵敏度）和静态 γ（γs，支配 bag2+链纤维，维持静态长度编码）。两类可能被**独立控制**，允许高级中枢根据任务精细调整传感器的灵敏度类型——但这在人类中的直接证据仍不充分。

## 关键机制

### 形态与分子特征

| 特征 | γ 运动神经元 | α 运动神经元 |
|------|------------|------------|
| 胞体大小 | 小（约 10–25 μm） | 大（约 40–80 μm） |
| NeuN 表达 | 低 | 高 |
| 靶纤维 | 梭内肌纤维（极端区） | 梭外肌纤维 |
| 产生力量？ | 否（太弱） | 是（主力） |
| 分子标记 | Err3⁺/Gfrα1⁺/Wnt7a⁺/5Ht1d⁺ | Err3⁻/Gfrα1⁻ |

**分子标记**（Wilkinson 2021，PMC9770680）：Err3（核激素受体）、Gfrα1（GDNF 受体）、Wnt7a（分泌蛋白）、5Ht1d（血清素受体）的组合表达具有相对特异性，可用于构建 γ 特异性工具（Cre 工具鼠、光遗传、DREADDs）。

### 动态 γ vs 静态 γ

```
动态 γ（γd）:
  靶纤维：bag1 → 调节动态灵敏度
  激活效果：Ia 传入对速度（dL/dt）的响应增强
  功能：让大脑对突然拉伸更加警觉

静态 γ（γs）:
  靶纤维：bag2 + 链纤维 → 调节静态灵敏度
  激活效果：维持/提高 Ia/II 型对持续长度的编码
  功能：防止肌梭在固定姿势或持续收缩时沉默
```

### α-γ 协同激活的计算意义

```
没有 γ 协同激活时（问题）：
  α 激活 → 梭外肌缩短 → 肌梭跟着缩短 → Ia 停止放电
  → 大脑失去本体感觉反馈（运动时最需要的时刻）

有 γ 协同激活时（解决方案）：
  α+γ 同时激活 → 梭外肌缩短，同时梭内纤维极端区也缩短
  → 梭内纤维赤道感觉区维持张力
  → Ia/II 持续报告长度/速度
```

这可被理解为"预测性感觉配置"：γ 的激活预测了即将到来的肌肉状态变化，并提前配置传感器以在该状态下继续有效工作。

### β 运动神经元（融合型）

部分脊髓神经元（β 型）同时支配梭外和梭内纤维，功能介于 α 和 γ 之间。在低等脊椎动物（蛙、蜥蜴）中 β 型占主导；哺乳动物中 α 与 γ 功能分离是进化上的专化。
