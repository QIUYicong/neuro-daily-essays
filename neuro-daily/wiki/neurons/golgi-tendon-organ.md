# 高尔基腱器官 (Golgi Tendon Organ, GTO)

> **一句话定义**：位于肌腱与肌肉交界处、与肌纤维串联排列的本体感觉器官，通过 Ib 型传入纤维向脊髓传递肌肉张力（力量）信息，在静息状态下介导自身抑制（逆肌牵张反射），在步行站立相转变为兴奋性负荷信号，并与肌梭共同构建力量的主观感知。

## 当前理解

我们现在认为，GTO 是骨骼肌本体感觉系统的"力量维度"传感器，与肌梭的"长度维度"互补，共同构成完整的两维本体感觉基础。

关键现代修正（取代经典教科书描述）：

1. **不是高阈值安全阀**：GTO 在每次主动收缩时都放电，即使最小的运动单元（S型慢缩单元）的收缩也足以激活（Jami 1992）。这与"只在危险高张力时才激活"的旧图景根本不同。

2. **不是步态的单纯抑制器**：在步行站立相，来自脑干的下行信号关闭 Ib 抑制性通路，激活 Ib 兴奋性通路，GTO 的负荷信号转而延长伸肌激活（Dietz & Duysens 2000；Pearson 2004）。

3. **"折刀反射"主要不是 GTO 的工作**：痉挛的突然放松主要来自 III/IV 类传入的激活，非 GTO。

## 关键机制

### 结构层次

**解剖位置**：
- 肌腱与肌肉交界处（musculotendinous junction）
- 与肌纤维**串联**排列（vs 肌梭的并联）→ 对张力高度敏感
- 每块肌肉 30–90 个 GTO
- 每个 GTO 连接 3–25 根来自不同运动单元的肌纤维

**内部结构**：
- 外包纤维结缔组织囊（约 1–2mm 长）
- 囊内：胶原纤维束 + Ib 传入末梢交织排列
- Ib 纤维在囊内失去髓鞘，分叉成葡萄状无髓末梢（spray endings）
- 末梢缠绕胶原束，在胶原受张力收紧时被机械挤压

**力学放大**：胶原束在受力时从卷曲（crimp）状态拉直，挤压 Ib 末梢，产生比整体张力更集中的局部力。主动收缩（力集中在少数胶原束）比同等程度被动拉伸（力分散）更有效激活 GTO。

### 传入纤维特性

| 特性 | 参数 |
|------|------|
| 纤维类型 | Ib（有髓，A类） |
| 直径 | 12–20 μm |
| 传导速度 | 70–120 m/s |
| 激活阈值 | 极低（每次主动收缩） |
| 适应性 | 中等适应（数秒内适应持续张力，但静态相仍保持放电） |
| 可调增益 | **无**（无γ运动神经元对等物，阈值相对固定） |

### 脊髓三条通路

**通路①：Ib 抑制性（静息/摆动相主导）**
- Ib 传入 → 脊髓 Ib 抑制性中间神经元 → 甘氨酸能抑制同肌 α-MN
- 效果：自身抑制，降低同肌张力
- 同时：激活拮抗肌（与 Ia 互抑方向相反）

**通路②：Ib 兴奋性（站立相激活）**
- Ib 传入 → Ib 兴奋性中间神经元 → 激活伸肌 α-MN
- 效果：负荷信号延长站立相
- 由下行网状脊髓束信号在站立相选择性激活

**通路③：上行至小脑（DSCT）**
- Ib 传入 → 背侧脊髓小脑束（DSCT）神经元
- 与 II 型传入（肌梭次级）在 DSCT 神经元汇聚
- 为小脑提供实时力量反馈，用于前馈运动校正

### 步态中的相位切换

| 步态阶段 | Ib 抑制性通路 | Ib 兴奋性通路 | 净效应 |
|---------|-------------|-------------|--------|
| 站立相（负重）| **关闭**（下行调制）| **激活** | GTO 负荷信号延长支撑 |
| 摆动相（空中）| 激活 | 关闭 | 自身抑制，协助腿抬起 |

切换机制：CPG 在站立相启动前突触抑制，选择性抑制 Ib 抑制性中间神经元的突触前末梢。
