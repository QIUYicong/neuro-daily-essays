# 外径向神经胶质细胞 (Outer Radial Glia, oRG / bRG)

> **一句话定义**：一类已从脑室面脱离、居于外脑室下区（OSVZ）的皮层神经干细胞，保留基底突起但无顶端附着，在人类和灵长类皮层发育中大量存在，可能是人类皮层体积扩张的关键细胞类型之一。

## 当前理解

我们现在认为，外径向神经胶质细胞（oRG，也称基底径向神经胶质细胞 bRG）是 2010 年在人类胎儿皮层中首次被充分描述的祖细胞类型（Hansen 2010, PMID: 20154730），代表了人类和灵长类大脑与小鼠大脑的一个关键细胞学差异。

oRG 与顶端径向神经胶质细胞（vRG/aRG）的核心区别：**无顶端突起**（已脱离脑室面），**保留基底突起**（仍可为神经元迁移提供导轨）。这种形态使它们居于外脑室下区（Outer SVZ, OSVZ），在人类妊娠中期至晚期形成一个数量巨大的增殖带。

oRG 能自我更新、产生中间祖细胞（IP）或直接产生神经元，通过**有丝分裂体体转位（MST）**分裂——细胞核在分裂前沿基底突起快速向软膜方向移动，然后就地完成分裂。

**重要限制**：oRG 的数量并非皮层沟回（gyrification）的充分条件。无沟回的狨猴和有沟回的豚鼠均有丰富的 oRG，说明皮层折叠涉及 oRG 增殖的速率、时序和生物力学因素，而不仅仅是细胞数量（Cardenas & Bhatt 2011, PMCID: PMC3256413）。

## 关键机制

**有丝分裂体体转位（MST）**
- oRG 分裂前，核沿基底突起快速向软膜侧移动（~微米/分钟）
- 分裂在当前核位置完成，而非在固定的顶端面
- 约 1/3 的 oRG 在雪貂 OSVZ 中表现 MST，其余进行静止分裂

**分裂产物**
- 自我更新（产生另一个 oRG）
- 产生中间祖细胞（IP / bIP）
- 直接产生有丝分裂后神经元

**与 vRG 的分子相似性**
- 共享标志物：Sox2, PAX6, NESTIN, GFAP
- 与 vRG 的最大区别在于缺少顶端附着（CENPB、ZO-1 等顶端连接蛋白的缺失）
