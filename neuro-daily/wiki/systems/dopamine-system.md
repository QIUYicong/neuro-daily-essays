# 多巴胺系统（总览）(Dopamine System Overview)

> **一句话定义**：以中脑腹侧被盖区（VTA）和黑质致密部（SNc）为起点的两条主干通路（中脑边缘和黑质纹状体），通过相位性爆发（奖励预测误差）和紧张性背景放电，分别调控奖励学习/动机/认知控制与习惯性运动学习；系统内部存在功能异质性，外侧缰核（LHb）→ RMTg 路径实现负预测误差的回路传递。

## 当前理解

多巴胺系统由两大解剖核团和其投射网络构成：

**腹侧被盖区（VTA，A10）**：
- 中脑边缘通路：VTA → 伏隔核（NAc）→ 奖励/动机
- 中脑皮层通路：VTA → 前额叶（PFC）→ 工作记忆/认知门控
- 参见 [[vta]] 页面的详细解析（功能异质性、投射拓扑）

**黑质致密部（SNc，A9）**：
- 黑质纹状体通路：SNc → 背侧纹状体 → 习惯性动作学习/运动控制
- SNc 多巴胺神经元死亡 → 帕金森病的运动症状

**功能分工**：
- **相位性爆发（>20 Hz）**：编码奖励预测误差（δ = 实际−预期），实现 TD 学习
- **紧张性放电（~4 Hz）**：设定系统基础多巴胺水平，影响背景动机状态

**负向反馈通路（LHb→RMTg→DA）**：奖励低于预期时，外侧缰核爆发 → GABA 能 RMTg 激活 → 抑制 94% 的多巴胺神经元，实现 δ<0 的回路级表达
