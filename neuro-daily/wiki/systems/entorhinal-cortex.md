# 内嗅皮层 (Entorhinal Cortex, EC)

> **一句话定义**：内颞叶的多模态皮层区域，是海马的主要输入/输出中继；内侧内嗅皮层（MEC）含网格细胞，外侧内嗅皮层（LEC）整合情境感觉信息；两者共同构成海马认知地图的"上游信息汇"，也是阿尔茨海默病最早受损的皮层区域之一。

## 当前理解

我们现在认为，内嗅皮层（EC）是连接多模态感觉皮层（经嗅周皮层/旁海马回）与海马记忆系统的核心门户——它不只是被动中继，而是进行重要的**预处理和抽象化**：

- **内侧内嗅皮层（MEC）**：主要编码空间信息。含网格细胞（Layer II）、头朝向细胞、联合细胞（Layer III/V）、边界细胞；为海马提供空间坐标和路径整合更新
- **外侧内嗅皮层（LEC）**：编码非空间情境信息（物体、气味、社会情境）；整合当前感觉情境为海马编码提供"什么"信息

两者的整合在海马形成完整的情节编码（"在哪里"×"有什么"）。MEC-LEC双流整合是情节记忆空间-情境双重编码的解剖基础。

阿尔茨海默病中，EC（尤其是内嗅皮层第II层星状细胞）是神经纤维缠结（Tau病理）最早侵入的皮层区域——在临床症状出现之前，EC Layer II 的MEC网格细胞就已开始退化，这解释了AD早期空间迷失先于语言退化的临床现象。

## 关键机制

### 1. 解剖位置与连接

- 位于颞叶内侧，紧靠海马，是大脑皮层与海马之间的主要接口
- 接受来自：嗅皮层（嗅觉）、旁海马回（视觉空间）、额叶（情境/注意调制）
- 投射至：海马（通过穿透纤维，perforant path）→ 齿状回 → CA3 → CA1
- 接受海马反馈：CA1/下托（subiculum） → EC Layer V/VI
- 也有直接EC→CA1投射（Temporoammonic pathway）

### 2. MEC 的层级功能组织

- **Layer II（星状细胞/岛状细胞）**：主要含网格细胞；提供空间度量坐标
- **Layer III（锥体细胞）**：含联合细胞（网格×头朝向×速度）；路径整合更新的核心层
- **Layer V/VI（深层）**：接受海马反馈；调制EC输出；含更多联合细胞

### 3. EC 作为阿尔茨海默病的早期靶点

Braak分期（1991）：AD神经纤维缠结（Tau病理）的扩散从**EC Layer II 星状细胞**开始，然后扩散到海马，再到前额叶和其他皮层。
- 阶段I-II：仅EC受累
- 阶段III-IV：海马受累，出现记忆症状
- 阶段V-VI：新皮层广泛受累

这意味着：当患者开始出现迷路症状时，EC的网格细胞已经在无症状期损坏了数年。EC网格细胞退化 → 路径整合失效 → 空间迷失是AD病理的最早功能后果之一。
