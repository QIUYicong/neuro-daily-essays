# 背侧语言流 (Dorsal Language Stream)

> **一句话定义**：双流语言网络中强烈左侧主导的通路，从后颞叶经顶叶到额叶下回BA44，通过弓状束承载音韵短期记忆和句法层级运算，支撑语言产出、复杂句子理解和语音工作记忆。

## 当前理解

我们现在认为，背侧语言流是大脑处理语言的两大平行通路之一，其核心功能是将声音模式映射到**发音动作**和**句法层级结构**。

**主要解剖节点（从后到前）**：
1. 初级听觉皮层（A1，Heschl's回）→ 颞平面（PT）：声音的时序特征提取
2. 后颞上回（pSTG）/ Wernicke区（BA22后部）：语音模式识别
3. **颞顶界面区（Spt，Sylvian parietal temporal area）**：音韵短期缓冲，工作记忆语音回路的颞叶锚点
4. 弓状束（AF）/ 上纵束（SLF）：主干白质通路，强烈左侧不对称
5. **BA44（pars opercularis）**：层级句法Merge运算
6. 运动前区（premotor）+ SMA + 运动皮层：发音程序化和执行

**两大核心功能**：

1. **音韵-运动映射**（声音→发音）：将感知到的语音序列转化为发音计划。这是语音模仿、重复能力和语言产出的基础。婴儿的"咿呀学语"（babbling）依赖这条通路的早期功能。

2. **层级句法运算**：BA44执行Merge操作，将词合并为短语再合并为句子，处理复杂的中心嵌入句（如"追我的猫的那只狗"）。猕猴不能学习需要层级运算的语法（AⁿBⁿ），但人类BA44可以。

**左半球主导性**：背侧流比腹侧流有更强的左半球优势。这与临床观察一致：左半球损伤导致严重的语言产出障碍（Broca失语），而右半球损伤对基本语言产出影响较小（更多影响语调和语用）。

## 关键机制

```
声音输入
    ↓
A1 → 颞平面（PT）：时序分析
    ↓
后颞上回（pSTG）：音素识别
    ↓
颞顶界面区（Spt）：音韵工作记忆缓冲
    ↓（弓状束，左侧主导）
BA44（Broca区后部）：Merge运算，句法层级建构
    ↓
运动前区 → SMA → 运动皮层：发音计划执行
```

**传导性失语的解剖意义**：Spt或弓状束损伤 → 音韵信息不能从颞叶送达BA44 → 能理解（腹侧流完整）+ 能产出（BA44从语义驱动）+ 但不能**重复**（音韵短期记忆断路）。这是背侧流特异性损伤的行为标志。
