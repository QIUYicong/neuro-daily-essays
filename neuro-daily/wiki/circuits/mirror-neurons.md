# 镜像神经元 (Mirror Neurons)

> **一句话定义**：镜像神经元是运动前区（猴F5，人类推测为BA44/BA45）中的一类神经元，在个体**执行**目标导向动作和**观察**他者执行同一动作时均会激活，被认为是动作理解和社会认知的神经基础。

## 当前理解

我们现在认为，镜像神经元是灵长类运动前皮层中一个独特的神经元亚群。原始发现来自1996年Gallese、Fadiga、Fogassi和Rizzolatti（PMID:8800951）在猕猴运动前区F5的记录：532个F5神经元中，约17%（92个）在猴子自己执行有目标的动作（如抓取食物）和观察实验者执行同一动作时均会激活，对无意义运动或单纯物体呈现则无响应。

猴子F5区与人类Broca区后部（BA44）高度同源（解剖位置、皮层层次结构、连接模式均对应），这一发现提出了"镜像神经元语言起源假说"（Rizzolatti & Arbib 1998）：人类语言网络可能借用了原本用于动作识别的镜像神经元回路，在演化中逐步发展出对层级句法结构的处理能力。

然而，**置信度被设为中等**，原因如下：（1）人类镜像神经元的直接记录数据极为有限（无法像猴子一样进行广泛侵入式记录）；（2）人类fMRI研究支持BA44在动作执行和观察中共激活，但分辨率不足以区分镜像神经元与普通运动神经元；（3）"镜像神经元是语言起源基础"的假说虽有解剖支持，但功能上的直接因果证据尚缺。

## 关键机制

- **双重激活**：执行期（motor system activation） + 观察期（visual input → premotor activation），均需目标导向动作
- **选择性**：对有目标的动作（抓、撕、拿）响应；对无意义运动不响应
- **F5区特点**：运动前区腹侧，与手部动作编码和口腔动作相关；直接与手部M1区连接
- **人类同源区**：BA44（Broca区后部），参与语言句法处理的区域；受损导致Broca失语
