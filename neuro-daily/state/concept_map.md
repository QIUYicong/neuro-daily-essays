## 已覆盖知识节点

### 分子层

- **Hodgkin-Huxley 模型（1952）**：动作电位的数学框架；电压依赖性钠/钾电导；四微分方程体系 → [2026-05-24]
- **电压门控钠通道结构**：α 亚基（260 kDa）+ β 亚基；四个同源结构域；S1-S6 跨膜片段；S4 门控电荷；IFMT 失活机制 → [2026-05-24]
- **NaV1.6**：成熟 AIS 主导亚型，激活阈值最低 → [2026-05-24]
- **NaV1.2**：发育早期 AIS 主导亚型，后被 NaV1.6 取代 → [2026-05-24]
- **AnkyrinG**：AIS 主要脚手架蛋白，直接结合 Nav II-III 连接子 → [2026-05-24]
- **βIV-spectrin**：连接肌动蛋白环的结构蛋白 → [2026-05-24]
- **KV7.2/7.3（KCNQ2/3）**：AIS 近端钾通道，设定静息膜电位 → [2026-05-24]
- **CK2 磷酸化**：调控 Nav1.2 与 AnkyrinG 结合 → [2026-05-24]

### 细胞层

- **动作电位**：全或无特性；去极化-复极化周期；Na⁺ 内流正反馈 + K⁺ 外流负反馈 → [2026-05-24]
- **轴突始段（AIS）**：20–60 μm；Nav 密度约为胞体50倍；分子架构三层；动作电位发起位点 → [2026-05-24]
- **AIS 稳态可塑性**：长度/位置的活动依赖性动态调整 → [2026-05-24]
- **AIS 细胞骨架**：平行微管束 + 周期性肌动蛋白环（~190 nm 间距）+ AnkyrinG 脚手架 → [2026-05-24]
- **Class 1 vs Class 2 神经元**：频率-强度关系的差异，H-H 相平面分析 → [2026-05-24]

### 突触层

- **反向传播动作电位（bAP）**：AIS 产生后逆向传入树突；与 Hebbian 可塑性 LTP 相关 → [2026-05-24]
- **树突 NMDA 棘波**：树突主动计算的证据；H-H 形式主义的扩展 → [2026-05-24]
- **人类 Ca²⁺ 棘波（L2/3 锥体细胞）**：人类特有发现；单神经元可解 XOR → [2026-05-24]

### 微回路层

- **吊灯细胞（Chandelier Cell）**：特异靶向 AIS 的抑制性中间神经元；控制尖峰时序；γ 振荡和工作记忆 → [2026-05-24]
- **跳跃式传导**：Ranvier 结节在有髓轴突上的功能；AIS 与节点共享分子架构 → [2026-05-24]
